01

认识 WorkBuddy

先搞清楚它跟聊天框的区别，看懂三栏

10 分钟
  • 它是工作台不是聊天框：交付的是文件
  • 左边找任务 · 中间说需求 · 右边验结果
  • 结果区能展开、收起，文件在「全部文件」里
▶ 打开 WorkBuddy，新建一个空任务，说出左中右三块区域分别有什么用。
本部分不涉及提示词，也不需要下载数据，先跟着讲一遍界面即可。
02

基础速览

把一句模糊需求变成它能执行的指令

20 分钟
  • 好任务 = 目标 + 输入 + 输出格式 + 约束
  • 三开关：模式日常办公 / 模型 Auto / 权限默认
  • 追问在原任务里改；交付前按六项验收
▶ 现在复制下面两条提示词，先跑通流程，不追求结果完美。
P1 新手起步 需要准备：无需资料，直接粘贴

第一次下任务：认一遍工作台

先跑通流程，不追求结果完美。重点看它会不会自己拆步骤。

请帮我梳理一份「保险代理人日常事务清单」，按下面要求输出：

1. 先列出我一天里最常重复的 5 件事，用一句话描述每件事。
2. 每件事标注：大概花多久、是否涉及客户隐私信息、是否可以交给 AI 先做一版。
3. 最后给出建议：哪 3 件事最适合优先交给 AI，为什么。

输出格式：一张 Markdown 表格 + 三段简短说明。
不要编造我没有提到的业务场景，不确定的地方标注「待确认」。
课堂回测看这里：看它是否先拆步骤再执行；右侧结果区是否出现文件。
P2 结果打磨 需要准备：承接上一条任务，直接粘贴

追问修改：把初稿改成能交的版本

不要重开任务，在原任务里追问，上下文才不丢。

在上一条结果的基础上继续修改，不要重做：

1. 把「最适合优先交给 AI」的 3 件事展开成行动清单，每件事写清：第一步做什么、需要准备什么资料、预计省多少时间。
2. 用「结论 — 依据 — 下一步动作」三段式重新组织，控制在 1 页以内。
3. 把涉及客户姓名、电话、保单号的部分全部替换成占位符（如「客户A」「保单X」）。

最后导出一份 Word 版本，文件名：代理人AI事务清单_v1。
课堂回测看这里：看能否在原任务里连续改；导出文件是否真能打开。
03

任务一：客户经营

把散在各处的客户信息，变成能照着打的跟进表

30 分钟
  • 客户台账盘点：分层 + 排跟进优先级
  • 单客画像：找保障缺口 + 面谈切入话题
  • 合规要点：姓名脱敏，缺失信息标「待确认」
▶ 先下载配套的客户台账与客户A保障资料，放进同一个文件夹，再复制提示词 3 跑一遍。
P3 客户经营盘点 需要准备：上传：客户台账 Excel（姓名、保单、保费、最近联系时间）

客户台账盘点：排出本周跟进优先级

这是代理人最高频的场景：把散在各处的客户信息，变成一张能照着打的表。

请读取当前文件夹里的客户台账，帮我做一份「客户经营盘点表」。

按下面要求处理：
1. 字段识别：先告诉我表格里有哪些字段，哪些字段缺失或需要补充。
2. 客户分层：按「最近联系时间 + 已购保单数 + 年缴保费」三个维度分四层：
   A 重点维护 / B 稳定经营 / C 待激活 / D 长期未联系。
3. 输出一张盘点表，列为：客户编号 | 分层 | 关键事实 | 跟进优先级（1-3）| 建议动作。
4. 最后给出本周优先跟进的 5 位客户，每位写一句理由。

约束：
- 客户姓名统一显示为「客户A、客户B」，不要出现真实姓名。
- 台账里没有的信息不要推测，缺失处填「待确认」。
- 不修改原始台账文件，结果另存为：客户经营盘点表_v1。

单客画像：找出保障缺口和切入话题

拜访前 5 分钟跑一遍，面谈时心里有底。

请根据我上传的客户资料，生成一份「客户画像与保障缺口分析」。

按下面结构输出：
1. 家庭结构与责任期：家庭成员、主要经济来源、可能的风险敞口。
2. 已有保障梳理：用表格列出已购险种、保额、缴费情况，并标出信息缺失项。
3. 保障缺口判断：从「重疾、医疗、意外、寿险、养老」五个维度，分别判断
   是否充足，并说明判断依据（引用资料原文，不要自行假设）。
4. 面谈切入话题：给出 3 个自然的开场话题，语气要像顾问不像推销。
5. 待确认清单：列出我还需要向客户补充了解的信息。

约束：
- 所有保额、保费数字必须来自我上传的文件，不得估算。
- 缺口判断只做提示，不下结论，最终以公司核保规则为准。
- 客户信息全程脱敏，用「客户A」指代。

04

任务二：展业内容

把产品和异议素材，变成张嘴就能用的话术与文案

30 分钟
  • 异议话术库：8 类拒绝理由逐条给应答
  • 朋友圈与口播稿：一次产出多条不同风格
  • 合规要点：收益表述必须引用原文，不得改写
▶ 先下载产品资料摘要和客户异议记录，再复制提示词 5 跑一遍。
P5 话术生成 需要准备：上传：产品资料 + 你记录的客户异议（脱敏）

异议处理话术库：把被拒的理由变成应答

把客户最常说的拒绝理由整理进去，得到一套自己的应答手册。

请根据我上传的产品资料和客户异议记录，生成一份「异议处理话术库」。

按下面要求组织：
1. 先归纳出客户最常见的 8 类异议（例如：太贵了、要跟家人商量、已有保险了、
   不着急、担心理赔、不信任业务员、收益不如理财、身体健康不需要）。
2. 每一类异议按四列输出表格：
   异议类型 | 客户真实顾虑 | 应答话术（口语化，2-3 句） | 合规提示
3. 应答话术要求：先共情、再澄清、后提供信息，不要说教，不要贬低竞品。
4. 最后附一段「面谈自检清单」：哪 5 句话绝对不能说。

约束（非常重要）：
- 收益演示、保障责任、免责条款必须逐字引用我上传文件里的原文，不得改写。
- 文件里没有的表述，一律不要自行发挥，标注「待补充」。
- 话术只是参考稿，必须经公司审核后才能对客使用。

朋友圈与短视频文案：一次产出多条

同一批素材，让它出不同风格的版本，你挑能用的。

请根据我上传的资料，帮我写一批可用于朋友圈和短视频的口播文案。

分三组输出，每组 3 条：
1. 「知识科普型」——讲一个保险常识或常见误区，每条 60–80 字。
2. 「客户故事型」——用脱敏后的真实场景讲一个转变，每条 80–100 字。
3. 「日常经营型」——服务提醒、节日问候、理赔协助等，每条 40–60 字。

另外再输出：
4. 三条短视频口播稿，每条 30 秒左右（约 90–120 字），开头 3 秒必须抓人，
   并标注适合的拍摄场景（如办公室、客户家里、户外）。

约束：
- 不得出现「保证收益」「稳赚不赔」「最好」「第一」等违规用语。
- 不得使用未经授权的客户真实姓名、照片、保单信息。
- 涉及产品的表述以我上传的资料为准，不自行添加卖点。
- 每条文案后面标注：适合发布时间。

任务三：方案与团队

把零散信息组织成能交出去的方案书与周报

30 分钟
  • 保障方案建议书：从需求分析到方案框架
  • 团队周报：分类归纳 + 算达成率 + 排位次
  • 合规要点：不承诺承保、不出现具体产品与费率
▶ 先下载家庭情况、保障清单与产品资料；团队周报另需工作记录与业绩表，再复制提示词 7 跑一遍。
P7 方案建议 需要准备：上传：客户家庭与保障情况（脱敏）+ 公司产品资料

保障方案建议书：从需求到初稿

这是它的强项：把一堆零散信息组织成一份结构完整的建议书。

请帮我起草一份「家庭保障方案建议书」初稿，用于面谈时向客户讲解。

按下面结构写，输出为 Word 文档：
1. 家庭情况概述：成员、责任期、主要风险关注点（只写资料里有的）。
2. 需求分析：从重疾、医疗、意外、寿险、养老五个维度，逐项说明
   「为什么需要」和「大概需要多少保额」，并写明测算依据。
3. 方案框架：给出建议配置的险种方向和优先级排序，说明理由。
   （只写险种方向与理由，不写具体产品名称和价格）
4. 预算区间建议：按低、中、高三档给出年缴保费区间。
5. 下一步动作：列出面谈时需要与客户确认的 5 个关键问题。

约束（非常重要）：
- 不承诺任何承保结果，不出现具体产品名称、费率和收益数字。
- 所有保额测算必须写明假设条件（收入、负债、家庭结构等）。
- 涉及公司产品与核保规则的部分标注「以公司正式文件为准」。
- 客户信息全程脱敏。文件名：保障方案建议书_客户A_初稿。

团队周报与业绩汇总：一次生成

主管岗最省时间的用法：把零散记录变成一份能直接发的周报。

请读取当前文件夹里的工作记录和业绩表，生成团队周报。

按下面结构输出：
1. 本周完成事项：按「增员、培训、陪访、业绩、客户服务」分类归纳。
2. 数据一览：团队出勤、拜访量、成交件数、保费达成率，用表格呈现，
   并对比上周与月度目标，标出差距。
3. 业绩排位：按保费达成率排出团队前 5 名，并标注与上月名次变化。
   （此部分仅用于内部管理，不对外传播）
4. 风险与卡点：列出本周暴露的 3 个主要问题及可能原因。
5. 下周计划：给出可执行的 5 条动作，标注负责人和完成时间。

另外单独生成：
6. 一段 150 字左右的《增员邀约话术》，用于邀请候选人参加事业说明会，
   语气诚恳、不夸大收益、不承诺收入。

约束：
- 所有数字必须来自我上传的表格，不得估算或补全，缺失填「待确认」。
- 业绩排位结果仅供内部管理使用。
- 不修改原始文件，结果另存为：团队周报_v1。
