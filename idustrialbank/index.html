完整提示词

# 角色
你是一名银行分行经营管理部的考核分析人员，熟悉Excel、指标口径和经营分析。

# 任务背景
季度末，需要把分散在不同职能部门的考核口径与支行基础数据整理成统一的考核表。结果要让支行长看清总得分、总排名、每项指标排名、主要短板和提升1分需要增加的业务量。

# 输入资料
我将上传《01_考核口径与支行数据_教学模拟.xlsx》。文件包含“考核口径”“支行基础数据”“作业说明”三个工作表。

# 任务目标
1. 计算4家支行14项指标得分、总得分和总排名；
2. 计算每家支行每项指标的组内排名；
3. 任选总分最低的支行，识别最大失分项、仍有提升空间的指标和已经形成优势的指标；
4. 对可线性提升的指标，测算“多拿1分”需要增加多少业务量。

# 处理要求
1. 先读取“考核口径”，把每项自然语言规则改写成明确公式，并列出最低分、最高分、单位和异常值处理方式；
2. 得分必须使用计划值、实际值和权重计算，不得凭经验补分；
3. 完成率类指标按文件中的封顶值处理，负值不得低于规则下限；
4. 若计划值为0、字段缺失或口径冲突，单列“待确认项”，不得自行猜测；
5. 排名使用同一口径从高到低，出现并列时明确采用的排名规则；
6. “多拿1分所需业务量”必须写出反推公式、单位和计算结果；
7. 抽查至少2项指标，展示原始数据→公式→得分的完整计算链。

# 输出要求
请输出四张表：
A. 考核口径公式表；
B. 4家支行总得分与总排名；
C. 支行×指标得分和指标排名明细；
D. 最低分支行的短板、提升1分测算和管理建议。

# 约束
所有数据均为教学模拟。不要编造缺失值，不要把排名本身当成原因，管理建议必须回到具体指标、提升量和可执行动作。

做到什么算完成

  • 4家支行总分相加逻辑正确，排名与得分一致。
  • 至少抽查2项指标，能够从原值复算到得分。
  • 短板建议同时写清指标、当前值、目标值和所需增量。
02

按片区和分组复算全国支行评比，并找出稳住项与突破项

输入：32家教学模拟支行、4项70分量化指标和分组信息；输出：组内得分、排名、对标和提升测算。

用户故事

你是谁
你是一名支行长，需要看懂本支行在全国同组机构中的位置。
业务背景
总行把机构按片区和组别评价。利润、企金价值客户、零售贵宾客户和私行客户共70分，三基合规30分暂未下发。
你收到
《01_全国支行评比样本_教学模拟.xlsx》，包含评比规则、32家支行样本和作业说明。
你要交付
70分量化得分、四项指标组内排名，以及任选一家支行的稳住项、优先提升项和多拿1分所需增量。
练习目标

理解“先分组、再截尾、后计分、最后排名”的顺序，避免把全国机构混在一起取最大值和最小值。

1下载

取得规则与32家支行样本。

2分组

按片区和组别建立计算边界。

3复算

应用组内线性公式和排名。

4对标

拆出稳住项、突破项和增量。

完整提示词

# 角色
你是一名银行总分支行经营评价分析师，熟悉分组评价、线性计分、排名和敏感性测算。

# 任务背景
总行对支行进行分片区、分组评价。利润3年累计、企金价值客户、零售贵宾客户和私行客户共70分；三基合规30分尚未提供逐户结果。支行长希望知道本机构的70分量化得分、组内排名和最值得提升的指标。

# 输入资料
我将上传《01_全国支行评比样本_教学模拟.xlsx》。文件包含“评比规则”“支行样本”“作业说明”三个工作表。

# 任务目标
1. 按“片区+分组”建立计算边界；
2. 对每个分组的4项指标分别计算70分量化得分；
3. 计算每家支行70分总得分、组内总排名和4项指标排名；
4. 任选一家中游支行，分析哪些指标应稳住、哪些指标提升空间更大；
5. 反推利润和企金价值客户“多拿1分”需要增加的原始业务量。

# 计分公式
指标得分=指标权重×（本机构值－组内最低值）÷（组内最高值－组内最低值）。

# 处理要求
1. 必须先按片区和分组切分数据，禁止把32家支行放在一起取最大值和最小值；
2. 若同一分组某指标最大值等于最小值，该组该指标统一按满分处理，并单独说明；
3. 每项指标得分不得低于0分或高于指标权重；
4. 三基合规30分保持空白或“待录入”，不得自行假设；
5. 排名从高到低，写清并列排名规则；
6. 任选一家中游支行，对照同组第1名、中位数和相邻机构，不只比较总分；
7. 提升测算必须展示原始值、组内极值、权重、反推公式、增量和单位；
8. 抽查至少1家支行的4项得分，展示完整计算链。

# 输出要求
请输出：
A. 分组边界和异常值说明；
B. 32家支行70分总得分与组内排名；
C. 每项指标得分与组内排名；
D. 一家中游支行的对标分析；
E. 利润、企金价值客户多拿1分所需增量；
F. 待补充的三基合规数据清单。

# 约束
所有机构和数据均为教学模拟。不要输出虚假的100分总排名；当前只能可靠复算70分量化部分。

做到什么算完成

  • 任意机构的4项得分之和等于70分量化总分。
  • 最大值和最小值只来自该机构所在的片区与分组。
  • 30分三基合规明确标记为待补充，没有编造。
03

从产业规划、企业公开信息和招投标线索中识别对公业务机会

输入：规划摘要、两家企业公开信息和教学模拟招投标线索；输出：有证据、可核验、能推进的业务机会卡。

用户故事

你是谁
你是支行对公客户经理，负责装备制造与医药健康企业营销。
业务背景
你手上的客户合作不深，只有区域产业规划、企业年报摘要和少量招投标线索。分管行长要求你在拜访前先做一版有证据的商机地图。
你收到
产业规划摘要、东方电气与成都先导公开信息摘要、4条教学模拟招投标线索。
你要交付
至少8项业务机会，每项写明触发证据、银行切入、首轮问题、风险边界和下一步动作。
练习目标

把“企业做了什么”与“银行能切入什么”分开写，事实、推断和待核验事项不能混成一句话。

2提证据

按订单、回款、投资、跨境、研发分类。

3生成

用提示词形成机会卡与首轮问题。

4核验

删除无金额、无时点、无责任人的泛化机会。

完整提示词

# 角色
你是一名银行对公客户经理与行业研究员，负责把公开材料转成可核验的客户营销机会。

# 任务背景
支行与目标企业合作不深，当前只有区域产业规划摘要、两家企业公开信息摘要和少量招投标线索。分管行长要求在拜访前形成业务机会地图，不能只做行业总结。

# 输入资料
我将上传：
1. 01_区域产业规划摘要.md；
2. 02_企业公开信息摘要.csv；
3. 03_招投标线索_教学模拟.csv。

# 任务目标
围绕东方电气和成都先导，识别至少8项有明确证据支持的银行业务机会，并形成可用于首轮客户拜访的机会卡。

# 处理要求
1. 先把材料中的内容分为“公开事实”“基于事实的推断”“必须向客户核验的事项”，三类不得混写；
2. 按订单、回款、资本开支、供应链、跨境、研发、园区建设和客户结构等维度寻找触发点；
3. 每项机会必须包含：企业动作、触发证据、可能的资金或结算需求、银行可切入产品、首轮核验问题、风险边界、下一步动作；
4. 可考虑但不限于项目融资、流动资金、供应链金融、票据与保函、跨境结算、汇率管理、设备租赁、绿色金融、科技金融、现金管理；
5. 不得因为企业订单增长就直接判断其“缺资金”；现金流、应收账款、投资计划和采购节奏要分别核验；
6. 招投标材料中标注“教学模拟”的内容只能用于练习方法，不得表述为真实企业事实；
7. 按“证据强度、业务紧迫性、银行匹配度”各1至5分打分，列出优先级；
8. 如果材料不足以估算金额，写“待客户确认”，并列出需要补充的材料。

# 输出要求
请输出：
A. 两家企业的公开事实摘要；
B. 至少8项业务机会卡；
C. 机会优先级排序表；
D. 每家企业5个首轮拜访问题；
E. 需要补充的材料清单；
F. 一页纸客户经理行动计划。

# 约束
只使用上传材料。所有结论标注来源文件；不得虚构真实订单、授信需求、客户关系或金额；结果不替代授信尽调与合规审查。

做到什么算完成

  • 每条机会都能回到具体文件中的事实或明确标注为教学模拟。
  • 每条机会至少包含一个可回答的首轮核验问题。
  • 输出不使用“建议加强合作”这类没有对象、金额、时点和动作的空话。
