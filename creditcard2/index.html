② 用户故事生成提示词（点击复制）
PROMPT · 用户故事 
你是一位资深产品经理。请根据以下业务背景，帮我展开用户故事。

【业务背景】
产品名称：[填写产品名]
核心功能：[一句话描述要做什么功能]
目标用户：[主要使用者是谁]
核心痛点：[当前用户遇到什么问题]
业务目标：[希望达成什么商业价值]

【输出要求】
1. 生成5-7个核心用户故事，格式为：
   "作为一个 [角色]，我想要 [功能/动作]，以便于 [商业价值/收益]"
2. 生成2-3个边界场景用户故事
3. 生成2-3个异常处理用户故事
4. 按建议的实现顺序排列
5. 标注每个故事的优先级（P0/P1/P2）

【注意事项】
- 用户故事要聚焦"做什么"和"为什么"，不要替开发写"怎么做"
- 每个故事必须是独立的、可测试的
- 边界场景至少覆盖：数据为空、数据超量、权限不足三种情况

② 基于 PRD 撰写高保真原型
PROMPT · 高保真原型 
请基于上面生成的 PRD，撰写一套高保真原型。

【要求】
1. 按 PRD 的核心功能模块，输出每个关键页面的结构与布局
2. 标注每个页面的核心元素：标题、输入框、按钮、列表、状态提示
3. 描述页面之间的跳转关系与主流程
4. 覆盖主流程、边界场景、异常处理三类界面
5. 输出可交付的前端实现思路（如采用 HTML + 原生 CSS，单文件可运行）

【输出格式】
- 先给页面清单（编号 + 名称 + 作用）
- 再逐一描述每个页面的高保真布局
- 最后给出主流程的页面跳转链路
