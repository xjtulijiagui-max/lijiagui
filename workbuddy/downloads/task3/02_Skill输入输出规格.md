# “存量客户经营周闭环”Skill 输入输出规格

## 触发语

- 生成周行动
- 复盘存量客户
- 制作网点经营作战包

## 必需输入

1. `00_规则/`：字段字典、风险与外发规则、资源表。
2. `01_输入/`：本周脱敏支行周报。
3. `02_过程/`：SOP v1.0、字段映射表、人工确认记录。
4. `03_模板/`：质量报告、机会清单、行动台账、风险清单、管理摘要与反馈模板。

缺少任一类输入时先报错，不进入处理。

## 输出

- `01_质量报告.md`
- `02_标准明细.csv`
- `03_机会清单.csv`
- `04_行动台账.csv`
- `05_沟通提纲.md`
- `06_风险清单.md`
- `07_管理摘要.md`
- `08_反馈模板.csv`
- `run-log.json`：记录输入版本、闸门、人工确认和停止原因。

## 停止条件

- 发现未脱敏个人信息。
- 文件缺失、字段含义或单位冲突。
- 机会没有规则或证据依据。
- 请求自动联系客户、修改客户标签、给出授信或购买结论。

## 人工确认点

- 字段映射、更正记录、经营机会、行动台账、对客话术、最终外发。
