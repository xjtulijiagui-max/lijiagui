# 海岳银行零售支行周报字段字典（教学模拟）

适用周次：2026-W32。所有机构、人员、客户与金额均为虚构聚合数据。

| 标准字段 | 类型 | 必填 | 合法范围 / 规则 | 常见别名 |
|---|---|---:|---|---|
| `week` | 文本 | 是 | `YYYY-Www`，本次应为 `2026-W32` | 数据周、周次、reporting_week |
| `branch_id` | 文本 | 是 | `B001` 至 `B999` | 网点编号、branch_code |
| `branch_name` | 文本 | 是 | 与网点编号一一对应 | 网点名称、branch |
| `customer_segment` | 文本 | 是 | 只允许聚合客群，不得出现个人姓名 | 客群、segment |
| `eligible_customers` | 整数 | 是 | 0 至 5000 | 可经营客户数、eligible_count |
| `contacted_customers` | 整数 | 是 | 0 至可经营客户数 | 已联系客户数、contacted_count |
| `appointments` | 整数 | 是 | 0 至已联系客户数 | 预约数、appointments_count |
| `completed_contacts` | 整数 | 是 | 0 至已联系客户数 | 有效沟通数、completed_count |
| `balance_wan` | 数值 | 是 | 单位为万元，非负数 | 资产余额万元、aum_ten_thousand |
| `risk_review_count` | 整数 | 是 | 非负数；仅表示待人工复核数量 | 风险待核数、risk_pending |
| `data_owner` | 文本 | 是 | 必须是岗位责任人，不得为空 | 责任人、owner |
| `report_date` | 日期 | 是 | `YYYY-MM-DD`，不得晚于汇总日 | 生成日期、generated_on |

## 质量闸门

1. 周次、字段口径或单位冲突时停止汇总，先生成待确认清单。
2. 可经营、已联系、预约、有效沟通必须满足逐级不增关系。
3. 缺少责任人、报告日期或网点编号时，记录为阻断项。
4. 只处理客群级聚合数据；若出现姓名、证件号、完整手机号、银行卡号等个人信息，立即停止并报告。
5. `risk_review_count` 不能被解释为客户风险结论，只能作为人工复核工作量。
