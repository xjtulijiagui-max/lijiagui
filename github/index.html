# GitHub 中文资源发布面板 · 使用说明

这是一个把「GitHub Publisher」Skill 封装成的本地网页发布工具。

## 功能
1. 粘贴 GitHub 仓库 / 网页链接，或选择本地 HTML/Markdown 文件，或直接粘贴文本。
2. 自动抓取来源内容，生成符合主站风格的简体中文资源页（含目录、搜索、复制正文）。
3. 编辑标题、slug、分类、标签等元数据。
4. 一键发布：页面 + nav-meta.json + 自动收录到 /list/ 导航。
5. 全部通过 GitHub Contents API 完成，无需 clone 仓库。

## 启动方式
双击 run-panel.bat，或运行 python server/app.py
浏览器自动打开 http://127.0.0.1:8730/

## 发布目标
- 主站：https://xjtulijiagui-max.github.io/lijiagui/
- 仓库：xjtulijiagui-max/lijiagui（main 分支根目录）
- 凭据：复用本机 Git Credential Manager 的 GitHub token

本页即由该面板自身发布生成，用于验证端到端发布链路。
