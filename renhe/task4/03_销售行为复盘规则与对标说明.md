# 销售行为复盘规则与对标说明（教学模拟）

## 一、什么叫"稳定模式"

只有同时满足以下条件，才能判定为一个行为模式：

1. 在 **3 次以上不同客户/场景** 中重复出现；
2. 有转写原文或台账记录支持；
3. 与结果指标（约访、成交、周期、客单价）存在可解释的关联。

只出现一次的问题写进"偶发现象"，不进入诊断结论。

## 二、十项能力维度定义

| 维度 | 观察什么 |
|---|---|
| 开场 | 前 10 分钟是否建立议题和信任，还是直接进入产品介绍 |
| 需求挖掘 | 是否区分"客户说的"与"客户没说的"，是否追问现状与影响 |
| 提问层级 | 是否有封闭→开放→假设性提问的递进，还是只有封闭式确认 |
| 倾听 | 是否打断、是否接住客户抛出的线索（如扩产、预算流程） |
| 决策链 | 是否识别决策人、影响人、经办人，并推进接触决策人 |
| 价值塑造 | 异议时是否把价格差异拆成可比较的价值单元 |
| 方案表达 | 是否分层（先结论后细节），是否匹配客户预算口径 |
| 异议处理 | 是否先分类（价格/信任/时机/权限）再回应，是否让步过快 |
| 成交推进 | 是否约定带日期、带责任人、带范围的下一步 |
| 客户洞察 | 是否利用客户主动给出的业务信息（如扩产）创造下一次机会 |

## 三、三档销售行为画像（用于对标）

| 行为项 | 普通销售 | 优秀销售 | 顶尖销售 |
|---|---|---|---|
| 开场 | 讲产品 | 讲议题 | 讲客户的业务目标 |
| 需求挖掘 | 记录需求 | 挖掘需求背后的影响 | 帮客户看见未表达的风险 |
| 决策链 | 等客户引荐 | 主动识别并请求引荐 | 设计多线接触，直接参与预算讨论 |
| 异议处理 | 解释或让步 | 拆解异议并给证据 | 预判异议，提前化解 |
| 成交推进 | "我发您看看" | 约日期和责任人 | 让客户承诺内部动作，自己锁定时间表 |
| 方案交付 | 9 天+ | 5 天 | 3 天以内，且分模块交付 |
| 客户洞察 | 完成交易 | 复购加保 | 从业务变化中创造新需求 |

## 四、复盘结论的表达规则

- 每条重要结论必须按"现象 → 多次证据 → 行为模式 → 成交影响 → 改进动作"五步写；
- 引用转写原话每条不超过 1 句，脱敏引用，不出现可识别信息；
- 证据不足的判断必须标注"待验证"；
- 优先级只取对成交影响最大的 3 件事，不并列十条。

## 五、隐私红线

- 报告中不得出现客户名称、企业名、联系人、电话、微信、邮箱、地址；
- 统一使用"某制造业企业客户""某贸易公司客户"等匿名指代；
- 涉及具体金额时保留数量级，去掉可识别的精确值；
- 不得把客户的健康、员工薪酬等敏感信息写入报告。
