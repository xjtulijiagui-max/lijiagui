M1

认知破冰：从"会问"到"能交付"

先定边界，再谈效率；先走通一次，再谈复用
对应课件 P06—P17 ｜ 约 30 分钟
S01

画一张"任务边界卡"，把红线写在开工之前

做什么
  1. 把你要做的那个任务写出来（一句话），然后判定它的数据等级：绿（公开）、黄（内部方法）、红（客户身份/交易/授信）。
  2. 写清 AI 做哪一段、人做哪一段、系统管哪一段。
  3. 写下这个任务"绝对不能做"的三件事。
  4. 如果落在红区，直接停 —— 换一个模拟任务来练，不要试。
可复制提示词
P01任务边界卡生成 
你是银行{{org}}的合规与效率双重视角的顾问。我要做的任务是：【用一句话描述任务】。

请输出一张不超过一页的"任务边界卡"，包含四块：
1）数据等级：绿（公开政策/通用模板）/ 黄（内部方法，间接可识别）/ 红（客户身份、交易、授信资料），并说明判断理由；
2）三方分工：AI 负责（读、整理、计算、初稿）、人负责（目标、事实、口径、签字）、系统负责（权限、留痕、归档）；
3）三条禁止动作：针对这个任务，写出绝对不能做的三件事；
4）开工条件：需要哪些授权、哪些材料、谁复核，任一条不成立就先不要开始。

要求：不确定的地方标"待确认"，不要替我判断合规结论。最后用一句话总结"这件事在什么条件下可以开始"。
做到什么算通过
  • 能一句话说出这个任务的数据等级和理由
  • 三方分工里，"人负责"的每一项都写到了具体角色，而不是"领导把关"
  • 三条禁止动作是针对这个任务的，不是通用套话
S02

六个动作，把一次任务从需求走到交付

做什么
  1. 认三栏：左找任务、中提要求、右看成果。先确认当前工作空间和材料范围对不对。
  2. 建任务：一句话说清对象、目的、交付物、给谁用。
  3. 选配置：这个任务要不要 Plan？要不要挂专家或 Skill？能不能出网？
  4. 看计划：先审计划再执行，路径不清就别让它直接干。
  5. 改结果：在原任务里连续追问，不要每次重开。
  6. 做验收：打开右侧实际文件，按六项逐条查。
这一步不要写提示词，重点是把动作顺序变成肌肉记忆。做到"闭着眼睛知道下一步点哪里"，就算过。
S03

把"看着对"变成"查得到"：五步核验 + 六项验收

做什么
  1. 拿你刚生成的任意一份材料，做一遍五步核验：限定来源 → 定位证据 → 分清性质 → 交叉验证 → 人工抽检。
  2. 再按六项验收打分：能打开、内容对、格式对、范围对、可追溯、可交付。
  3. 把没过的那一项，写成一条具体的修改指令（不要写"再完善一下"）。
核验动作你要回答的问题证据写在哪
限定来源这次只查哪几份材料？材料文件名 + 版本
定位证据这个数字来自哪一段、哪一行？段落号 / 行 ID
分清性质这是事实、判断，还是待核实？标注在正文里
交叉验证另外一份材料是不是也这么说？两份来源并列
人工抽检我亲手抽查了哪三项？抽检记录

S04

实操一：三家企业走访材料，变成一页可交付纪要15 分钟 · 个人

背景：某支行零售客户经理走访了 3 家企业，带回了脱敏走访记录、上次沟通纪要和统一模板。你要在下班前交一页纪要 + 5 条行动清单 + 待确认清单。

拿材料
⬇01 走访记录 ⬇02 上次纪要与待办 ⬇03 纪要模板
可复制提示词
P02走访材料 → 一页纪要 
你是{{org}}的{{role}}的助理。请把本次走访材料整理成一页会议纪要。

【资料范围】只使用这三份文件：
1）01_走访记录_教学模拟.md
2）02_上次沟通纪要与待办.md
3）03_会议纪要模板.md

【第一步：先不写纪要】先列出材料清单，并指出完成一份合格纪要还缺哪些信息，说明每个缺口会影响哪一段结论。

【第二步：按模板生成】严格用模板的六段结构：基本信息 / 事实（有来源）/ 判断与推断 / 待确认事项 / 行动清单 / 风险与边界。
- 事实必须标注来源（文件名 + 段落），不得把客户口述直接写成已核实事实；
- 推断单独成栏，标注置信度（高/中/低）和依据；
- 行动清单每条必须有责任人和完成时间；
- 无法确认的责任人、时间、金额，一律写"待确认"，不得编造；
- 逾期未完成的待办要单独标出。

【第三步：自检】列出你这份纪要中最不确定的 3 处，并说明需要谁来确认。

【边界】不替代授信判断；不形成对客承诺；不改动原始文件。
做到什么算通过
  • 每条事实都能追到具体文件与段落
  • 5 条行动每条都有责任人和时间，没有一条是"尽快""抓紧"
  • 逾期待办（审计报告）被单独标出，而不是被合并进正文
  • 至少 3 处写了"待确认"，且说明了影响
做完先别急着交。用 S03 的五步核验过一遍，再回答：如果行长只问一句"这三家哪家最值得先跟"，你的纪要支持得住吗？

S05

建一个五目录工作空间，让材料各就各位

做什么
  1. 按 00_规则 / 01_输入 / 02_过程 / 03_输出 / 99_归档 建五个文件夹。
  2. 把资料包里的模板放进 00，模拟材料放进 01，本次生成的中间结果放 02，成品放 03。
  3. 用统一命名：YYYYMMDD_机构_任务_版本，例如 20261031_城东支行_保险开门红_V2。
  4. 在 00 里放一页"本任务说明"：目标、对象、验收标准、禁止动作。
可复制提示词
P03五目录工作空间初始化 
我要为{{org}}的一个具体任务建一个可复用的工作空间，任务名称是：【任务名】。

请帮我：
1）按 00_规则 / 01_输入 / 02_过程 / 03_输出 / 99_归档 五个目录，列出每个目录应该放什么、不该放什么；
2）给出命名规则和一个具体示例文件名（格式：YYYYMMDD_机构_任务_版本）；
3）生成 00_规则 目录里的"本任务说明"草稿，包含：目标、服务对象、材料范围与版本、验收标准、禁止动作、责任人；
4）指出这个任务中有哪些材料属于客户敏感信息，必须留在授权环境、不能进入这个目录。

要求：不要创建任何实际文件，只输出目录结构与说明草稿；不确定的字段标"待确认"。
做到什么算通过
  • 五个目录建好，且 01 里只有本次模拟材料
  • 00 里有一页说明，别人接手能看懂
  • 文件名符合命名规则，能一眼看出机构、任务、版本
S06

写一张角色卡：四件事决定它能不能用

做什么
  1. 给身份：岗位、服务对象、语气、禁区。
  2. 喂资料：制度、条款、模板、脱敏样例，每份标来源、版本、生效日、适用范围、责任人。
  3. 立规则：先后顺序、必填字段、冲突时以谁为准、缺资料就停、哪些动作必须人工确认。
  4. 做验收：正常、缺失、冲突各跑一次，看它会不会编、会不会漏、能不能停。
可复制提示词
P04岗位角色卡（含禁区与停止条件） 
请为{{org}}的{{role}}配置一个"{{org}}经营助手"角色卡。

按四块写，每块都要具体到能验收：
1）身份：岗位定位、服务对象、语言风格（专业、克制、不说绝对话）、三条禁区（例如不承诺收益、不替代审批、不越权取数）；
2）资料：列出这个角色必须读的材料类型，并为每类标注"来源、版本、生效日期、适用范围、责任人"五个字段；
3）规则：先做什么后做什么、哪些字段必填、口径冲突时以谁为准、缺资料时必须停下来问什么、哪些动作必须人工确认；
4）验收：设计三个测试样本（正常 / 缺失 / 冲突），分别写清"应该输出什么"和"什么情况下必须停止"。

最后给出一段可以直接粘进系统设置的角色描述（不超过 300 字）。

边界：不虚构制度条款；不确定的标"待确认"。
S07

盘一张资料资产地图：哪类任务用哪份材料

做什么

把你的材料按四类盘一遍，重点不是列清单，而是标出"缺什么、谁来补、什么时候失效"。

资料类型典型文件可用方式必须先补齐
制度与办法监管文件、内部制度、操作规程条款检索、摘要、对照检查版本、生效日、适用范围、责任人
产品与条款产品说明书、费率表、风险提示提取字段、产品对比、话术边界条款原文、更新时间、审批口径
客户与经营台账、活动记录、客户画像仅在授权内网分析敏感等级、授权范围、脱敏规则
模板与案例周报、纪要、方案、优秀案例复用结构、迁移方法去标识、客户授权、可公开范围
知识库分四层：制度库定依据、产品库定边界、案例库判能否迁移、模板库定交付形状。调用顺序是：模板定形 → 制度定依据 → 产品定边界 → 案例判断能否迁移。
S08

用好 Grill Me：把一句空话问成可执行任务5 轮追问

做什么
  1. 拿一句真实但空的话，例如"帮我策划一场财富沙龙"。
  2. 让 AI 一次只问一个维度：目标 → 输入 → 约束 → 流程 → 验收。
  3. 每轮你只回答你确实知道的，不知道的写"待确认"，不让 AI 替你编。
  4. 五轮之后，让它输出一页任务说明书。
可复制提示词
P05Grill Me 五轮追问 
我现在的需求是：【一句空话，例如：帮我策划一场财富沙龙】。

请用"每轮只问一个维度"的方式帮我把需求问清楚，不要一次抛一堆问题，也不要先给方案。

第 1 轮问目标：要达成什么业务结果？目标客群是谁？
第 2 轮问输入：有哪些可用材料？名单、产品、预算、场地、讲师、过往活动数据分别有没有？
第 3 轮问约束：合规口径、不得承诺的事项、客户隐私、行内审批要求分别是什么？
第 4 轮问流程：邀约—签到—内容—互动—会后跟进，每一段谁负责？
第 5 轮问验收：到场率、有效沟通数、会后备忘录、多少天内跟进，各自标准是多少？

规则：
- 每轮只问一个问题，等我回答后再进入下一轮；
- 我不知道的，我会回答"待确认"，此时你把它记入缺口清单，不要自行假设；
- 五轮结束后，输出一页任务说明书：目标、输入清单、约束、流程与责任人、验收标准、缺口清单。

最后提醒我：哪些事项属于必须人工确认的节点。
做到什么算通过
  • 五轮下来，"待确认"少于 3 项，或者每项都有明确的确认人
  • 任务说明书里的验收标准是数字，不是"效果好"
  • 流程每一段都有责任人，没有"大家一起"

P06会前简报（含三类标注） 
你是{{org}}的财富顾问助理。明天下午要拜访一位客户。请只基于以下两份材料生成会前简报：
- 07_客户画像_教学模拟.md
- 08_产品条款摘要_教学模拟.md

【硬约束】
1）不虚构任何客户信息；材料里没有的，写"待核验"；
2）不替代适当性判断，不做"建议买哪个"的结论；

4）不得出现"保本""稳赚""绝对安全"等表述。

【输出结构】
一、客户需求假设（3—5 条，每条标注"事实 / 推断 / 待核验"三态之一）
二、三项核心关切与优先级（说明依据）

六、待核验清单（谁来核、何时核）

【自检】最后用一句话说明：这份简报里最不能直接对客说的一句话是哪句，为什么。
做到什么算通过
  • 每条需求都带"事实/推断/待核验"标签，没有一条是裸结论
  • 5 个问题都是开放式，且能验证需求真假
  • 产品部分引用了具体条款，没有出现禁止表述
  • 明确写了"不做适当性判断，由持牌人员完成"
M3

技能体系：把经验变成可复用的 Skill

先判断值不值得做，再拆 IPO 与 SOP，最后才封装
对应课件 P30—P46 ｜ 约 90 分钟
S10

六问诊断：这件事值不值得先做一个小样

做什么

不用打分，凭业务常识回答"是 / 不是 / 不确定"。五个以上"是"，就值得先跑一个小样。

#问题为什么问
1经常重复吗？每周、每天都在做？频率决定复用价值
2资料找得到吗？文件、数据、记录齐吗？没材料就没有稳定输入
3结果说得清吗？知道最后要交什么？说不清交付物就没法验收

P16开门红作战方案（Plan 版） 
你是{{org}}保险业务负责人的方案参谋。请为 2027 年保险开门红生成一份"能明天开始执行"的营销作战方案，**先出计划，不要直接写正文**。

【先输出计划】材料清单与缺口 → 章节结构 → 每章要回答的问题 → 需要我确认的口径。

【方案结构】
1）背景与问题：用事实描述，不用空泛评价；点明人员、目标、外部环境三个约束；
2）目标与指标：中收、件数、活动量、转化率，写清口径与时间进度；
3）增长链：获客（五条渠道）→ 转化（五类高客 + 产品矩阵）→ 服务（T+1、30天、节点、年度、转介绍），三环用同一套客户 ID 与口径；
4）每日过程管控：08:00 晨会、08:30 筛名单、上午外拓、14:00 客户经营、16:30 夕会、17:30 数据复盘，每段写输入→输出→责任人→留痕；
5）看板：日看动作、周看转化、月看结构，每个异常写触发条件、今日动作、复核时点；
6）风险与红线：不编造、不承诺、不外传、不替代，四个必须人工确认的节点；
7）实施路径：里程碑、责任人、依赖条件；
8）复盘机制：节省时间、质量提升、错误减少、采纳率。

【硬约束】
- 不编造产品利益、客户资料、成功业绩、金额与时点；
- 不承诺保本保收益，非保证利益必须提示；
- 案例必须区分真实与教学模拟，无授权案例只能给模板与方法；
- 每条举措必须落到"谁、哪天、做什么、输入什么、输出什么、怎么检查"，落不到人和时间的标"待确认"。

【边界】本方案为教学模拟，不对应任何机构真实目标。
