# 交付验收单（六项 + 红线）

## 一、六项验收
| # | 项目 | 标准 | 通过 | 证据 |
|---|---|---|---|---|
| 1 | 能打开 | 文件真实存在、格式正常 | ☐ | |
| 2 | 内容对 | 事实、数字、结论可核对 | ☐ | |
| 3 | 格式对 | 版式、字段、命名符合要求 | ☐ | |
| 4 | 范围对 | 没漏做、没越界多做 | ☐ | |
| 5 | 可追溯 | 知道依据来自哪个文件 | ☐ | |
| 6 | 可交付 | 别人拿走能继续用 | ☐ | |

## 二、四条红线（一票否决）
- ☐ 不编造：产品利益、客户资料、成功业绩、金额与时点
- ☐ 不承诺：保本、保收益；非保证利益未说成确定收益
- ☐ 不外传：未授权客户身份、交易、授信与经营数据
- ☐ 不替代：适当性判断、授信审批、合规结论、责任签字

## 三、签字
- 制作人 / 复核人 / 日期
