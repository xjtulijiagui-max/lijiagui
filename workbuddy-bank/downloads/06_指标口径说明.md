# 周报指标口径说明（V1.2，2026-10 生效）

| 指标 | 口径 | 常见错误 |
|---|---|---|
| 存款日均 | 本周五个营业日日均余额 | 用期末余额冒充日均 |
| 贷款投放 | 本周新发放金额，不含续做 | 把续做计入新增 |
| 保险中收 | 已确认手续费收入，不含预收 | 把预收保费当收入 |
| 有效客户新增 | 满足有效户标准的新增客户数 | 把开户数当有效户 |

## 缺报处理规则（必须遵守）
1. 缺报网点在汇总表中单列，**不得补零**，不得用上月数据代替。
2. 口径不一致的网点，数据单列并标注差异项，不并入合计。
3. 汇总表必须附“口径版本 + 数据来源文件 + 生成时间”。
