练习一｜第一次完整任务：把走访材料变成可交付纪要

PPT 1615 分钟个人操作脱敏材料
背景

某支行零售客户经理一天走访了三家企业，带回语音转写要点、微信沟通摘要、两张现场照片，还有一份上个月没做完的待办清单。请你用 WorkBuddy 完成一次从材料到成果的完整闭环：不是写一段总结，而是产出能发出去、能被检查的纪要。

输入资料（下载后放入新建工作空间）
MD
练习一_走访材料包_教学模拟.md3 家企业转写要点 + 微信摘要 + 上次纪要 + 纪要模板 + 已知缺口
操作步骤
  1. 新建独立工作空间，只放本次材料的副本，不改原件。
  2. 先让它列材料清单与缺口，不允许它直接开始写纪要。
  3. 用 Plan 模式校准步骤与验收标准，确认后再执行。
  4. 生成纪要正文、行动清单、待确认事项三部分。
  5. 逐项核对数字、人名、时间、责任人，把错的改在源头而不是改结果。
可直接复制的提示词
PROMPT 01 · 从材料到纪要
# 角色
你是一名银行支行客户经理的助理，负责把走访现场材料整理成可交付的会议纪要。

# 任务
读取工作空间中的《练习一_走访材料包_教学模拟.md》，产出：
1. 一页会议纪要（按文件内模板结构）；
2. 行动清单（每条含责任人、完成时间、交付物）；
3. 待确认事项清单（每条含需要谁确认、期望时间）。

# 执行顺序（必须按序，不得跳步）
第一步：只输出材料清单与缺口评估，不写纪要。列出：有哪些材料、分别覆盖哪几家企业、缺什么、缺的东西会影响哪些结论。
第二步：等我确认后，输出执行计划：分几步、每步输入与输出、验收标准、遇到冲突时以谁为准。
第三步：按模板生成纪要，事实部分必须带来源标注（转写要点 / 微信截图 / 公开信息），并标注可信度（已确认 / 对方口头 / 待核验）。
第四步：生成行动清单与待确认清单。
第五步：自检并输出检查结果。

# 约束
1. 不得补造任何数字、金额、人名、时间、订单量、投资规模。
2. 材料里“多一成”“几千万”“两千万级”这类模糊表述，原样保留并标注“口径不明、无法换算”，不得自行折算成具体金额。
3. 上次遗留的 4 条待办，逐条标注当前状态（已完成 / 未完成 / 无进展），不得默认已完成。
4. 推断必须单独成段，并写明推断依据；推断不得写成事实。
5. 无法确认的信息统一写“待确认”，并在待确认清单里给出确认路径。
6. 不使用“高度重视”“进一步加强”“有效提升”这类没有动作的词。

# 自检项
- 每条事实是否都能找到来源？
- 每条行动是否都有责任人和完成时间？
- 是否有我臆造的数字？（请自己列出来核对）
- 待确认事项是否都写清了找谁确认？
- 纪要是否控制在一页以内？
交付物
一页会议纪要
5 条行动清单
待确认事项清单
验收标准
纪要事实有出处
每条行动有责任人和时间
无法确认的信息标记“待确认”，未编造
红线：客户、企业与数据均为教学模拟，不得替换为真实客户材料；不得把口头表述包装成已核实事实。

练习二｜喂养一个“财富客户会前助手”

PPT 2820 分钟2—3 人一组模拟客户
背景

明天下午要拜访一位 45 岁的企业主：家庭资金与企业资金混用，关注子女教育与养老，上次沟通时主动问过“有没有既能保本又能给孩子留一笔的”。手上只有产品条款摘要、脱敏客户画像和上次沟通纪要。你要在拜访前拿到一份会前简报和五个首轮问题——而不是一份话术稿。

输入资料
MD
练习二_会前材料包_教学模拟.md脱敏客户画像 + 三款产品条款摘要 + 上次纪要 + 会前简报模板
操作步骤
  1. 给助手一个角色与三条禁区，写进工作空间的规则文件。
  2. 从材料里选三份最相关的，说明为什么选它、排除了什么。
  3. 用 Grill Me 让它连续追问五轮，暴露你还没想清楚的地方。
  4. 输出会前简报与五个首轮问题。
  5. 用“事实 / 推断 / 待核验”三类标注，逐条核对。
可直接复制的提示词
PROMPT 02 · 会前简报 + Grill Me
# 角色
你是某银行支行的财富顾问助理，服务对象是支行客户经理。
你的输出只用于内部会前准备，不对客，不承担适当性判断。

# 三条禁区（写在最前面，后续所有输出都必须遵守）
1. 不虚构客户信息：材料里没有的，一律标“待核验”，不得推测成事实。
2. 不替代适当性判断：客户风险测评已过期，任何产品建议只能写成“可讨论方向”，不得写成“推荐”。
3. 不承诺收益：不得出现“保本”“稳赚”“保证收益”“锁定利率”等表述；非保证利益必须标注“不确定”。

# 输入
工作空间中的《练习二_会前材料包_教学模拟.md》，内含脱敏客户画像、三款产品条款摘要、上次沟通纪要、会前简报模板。

# 任务一：Grill Me（先做这个）
在开始写简报之前，请你反过来问我问题，一轮 5 个，连续 5 轮，共 25 个问题。
要求：
- 问题必须指向材料里缺失、模糊或互相矛盾的地方；
- 每轮问题后，告诉我“如果这个问题答不上来，简报里哪一段会写不下去”；
- 不要问我材料里已经写清楚的事；
- 每轮结束等我的回答，再问下一轮。

# 任务二：会前简报（Grill Me 结束后再做）
按模板输出，包含：
1. 客户基本情况（只列已知事实，逐条标来源）；
2. 本次拜访目标（最多 2 个，可衡量）；
3. 需求假设（每条标注：事实 / 推断 / 待核验，并给推断依据）；
4. 可讨论的产品方向与边界（说明“能说什么”“不能说什么”）；
5. 首轮 5 个开放问题（不带引导结论、不暗示答案）；
6. 合规提示（适当性重测、风险提示、双录、信息保护）；
7. 待核验清单与责任人。

# 特别要求
1. 客户问过“能不能随时取”——请正面回应这个问题在条款里怎么写的（减保满 5 年、每年不超过已交保费 20%、前 3 个保单年度现金价值低于已交保费），不得模糊处理。
2. 客户家庭资金与企业资金混用，请单独指出这一点的风险与需要核实的事项。
3. 教育金测算：只给计算方法与所需假设，不要编造收益率。假设缺失就列出来。
4. 产品方向最多 2 个，并说明为什么排除另外的产品。

# 自检
- 是否有任何一句话没有来源？
- 是否有任何承诺性表述？
- 五个问题是否都能让客户说出一段话，而不是回答“是 / 否”？
- 待核验项是否都有责任人？

练习三｜把“支行周报”做成一个 Skill

PPT 4525 分钟3 人一组教学模拟
背景

5 个网点提交周报，格式不一：有的用表格，有的写成一段话，有的指标名和分行口径对不上，还有一个网点根本没交。支行长每周一上午要看一页汇总，并且知道谁需要跟进。你要做的不是这次汇总完，而是让下周、下下周都不再重来一遍。

输入资料
XLSX
练习三_网点周报与应报名单_教学模拟.xlsx应报名单 / 指标口径说明 / 4 份格式不一的周报 / 汇总模板
操作步骤
  1. 写清适用场景与不适用场景——什么情况下不该用这个 Skill。
  2. 设计输入清单、处理步骤、异常分支和输出模板。
  3. 明确人工复核点与禁止动作（缺报不补零、口径冲突不合并）。
  4. 用正常样本跑一次：4 份格式不同的周报能否统一。
  5. 用缺报样本再跑一次，检查它会不会偷偷给你补零。
可直接复制的提示词
PROMPT 03 · 编写周报 Skill + 双样本测试
# 角色
你是某银行支行的经营分析助理，负责把 5 个网点的周报汇总成一页管理视图，并起草一个可复用的 Skill。

# 输入
工作空间中的《练习三_网点周报与应报名单_教学模拟.xlsx》，包含：
- 应报名单：5 个网点，其中 1 个未提交；
- 指标口径说明：5 项指标及各自的同义表述；
- 4 份网点周报：格式各不相同（表格 / 文字段落 / 指标名称不一致）；
- 汇总模板：目标输出结构。

# 任务一：先做口径对齐，不要直接汇总
输出一张“口径对齐表”，逐条写明：
- 周报里出现的原始指标名；
- 对应到分行的哪个标准指标；
- 判断依据（引用口径说明里的哪一行）；
- 无法对应的，单列“待确认”。
特别注意：开发区支行用了“储蓄存款/公司存款/小微贷款/活跃客户/代销保险收入”这套说法，必须说明如何映射，以及“含保证金 300 万需拆分”这一条怎么处理。

# 任务二：汇总一页管理视图
按汇总模板输出，要求：
- 每个网点一行，5 项指标完成率 = 累计实际 ÷ 累计计划；
- 最终展示保留 1 位小数；
- 乡镇支行标“缺报”，对应单元格留空，不得补 0，不得按平均估算；
- 增加一列“异常说明”，写清城西支行格式不合模板、开发区支行口径需确认、城东支行系统故障影响 3 单。

# 任务三：编写 Skill（这是本练习的主要交付）
输出一份可直接落地的 Skill 文件，结构如下：
1. 名称与适用场景（什么时候用、什么时候不该用）；
2. 触发条件（谁在什么时点触发）；
3. 输入清单（文件、必填字段、必须存在的口径说明）；
4. 处理步骤（按顺序，每步写输入 → 动作 → 输出）；
5. 判断规则（口径冲突怎么办、格式不一怎么办、同义指标怎么合并、金额单位怎么统一）；
6. 异常处理（缺报、重复报、字段缺失、单位错位、数字明显异常，各写一条处理规则）；
7. 输出模板（一页汇总的结构与字段）；
8. 人工复核点（哪 3 处必须人看）；
9. 禁止动作（至少 5 条，例如：不补零、不估算、不合并口径冲突项、不隐瞒缺报、不修改原始数字）；
10. 停止条件（满足什么情况必须停下来问人）；
11. 验收标准（怎么判断这次跑成功了）。

# 任务四：双样本测试
用同一份 Skill 跑两次，并输出测试记录：
- 样本 A（正常）：4 份已提交周报，检查是否格式统一、数字是否都能回到原表；
- 样本 B（异常）：把乡镇支行视为缺报，检查 Skill 是否会补零、是否会在汇总里漏掉这个网点、是否在异常列说明。
如果样本 B 跑不通，请修改 Skill 的规则，而不是修改输出结果。

# 约束
1. 所有数字必须能追溯到具体工作表的具体单元格位置。
2. 不得使用“整体较好”“稳中有进”这类没有指标的描述。
3. 不得把“完成率低”直接写成“原因是营销不力”——原因必须来自材料，材料没有就写“待核实”。
4. 输出必须能直接交给支行长，不需要二次加工。

测试记录（正常 + 异常两组）

缺报不补零
版本冲突单列

第一轮提示词：生成初版方案
PROMPT 07 · 综合实战（第一轮）
# 角色
你是中国邮政储蓄银行某支行的保险业务负责人，正在制定 2027 年保险开门红营销策划方案。

# 业务背景
支行保险业务面临四个挑战：
1. 任务持续增长，每年销售任务不断提高；
2. 营销力量不足，人员减少、人均产能要求更高；
3. 外部环境承压，客户预期变化、销售难度增加；
4. 传统打法触顶，压力传导、高频开口、专业营销、全员营销这四招已经充分使用，增量空间有限。

核心问题：当传统营销动作已经接近极限，如何在人员减少、目标提高的条件下，借助 AI 实现保险业务的新增长？

# 输入资料
工作空间中的《综合实战_资料清单与模拟数据_教学模拟.xlsx》，以及你所在支行提供的产品条款与历史方案（如有）。
请先检查文件夹：哪些资料已取得、哪些缺失、缺失会影响哪些章节。资料缺失必须列出缺件清单，不得假装已经读取。
外部资料须标注来源、日期和适用范围。

# 任务目标
形成一份能让支行真正执行、管理层能检查、每日能督办、最终能复盘的方案，围绕三个环节：

## 1. 获客：扩大漏斗
在商协会、工业园区、乡镇合作、存量 VIP、转介绍的基础上，设计：商协会战略合作与批量获客机制；园区、乡镇、企业主群体的精准外拓；企业家沙龙、财富讲座、客户培训；存量高净值客户挖潜与老客户转介绍；AI 辅助客群识别、名单分析与活动策划。
必须回答：客户从哪里来？谁负责获取？每天做什么？怎样衡量获客效果？

## 2. 转化：从洞察到成交
围绕高净值客户五类特征设计洞察模型：可支配闲置资金规模；家庭结构复杂，有传承、婚姻与家庭保障需求；企业经营风险集中，有家企资产隔离需求；关注健康、子女教育、家庭责任；关注资产安全性与长期规划。
在依法合规、充分了解客户实际需求与风险承受能力的前提下：建立客户分层与需求洞察模型；分析主力产品的实际条款、适用人群、保障责任、利益结构与风险；建立产品与需求匹配矩阵；设计沟通、异议处理、成交推进与跟进流程；设计客户经理培训、陪访、过程辅导机制。
必须回答：为什么客户需要这类方案？为什么选择适合自己的产品？如何提高有效沟通与合规转化的成功率？

## 3. 服务：通过经营创造持续增长
保单服务、客户回访、重要节点提醒；家庭保障需求变化跟进；满意度评价；经客户授权的真实案例整理与传播；合规的转介绍与长期关系维护。
必须回答：成交之后如何持续提供价值？怎样把优质服务转化为信任与转介绍？

# 方案结构（至少包含 12 章）
1. 经营背景与问题诊断；2. 目标体系与指标分解（到月、周、日、团队、个人，说明测算口径）；3. 获客专项作战方案；4. 客户洞察与产品匹配；5. 成交推进与转化管理；6. 客户服务与转介绍；7. 每日过程管控机制；8. 每周与每月经营复盘；9. 成功案例与经验复制；10. 组织分工与保障；11. 合规与风险控制；12. 执行附录（六张表）。

第七章必须是重点：细化到每天不同时间段的行动、责任人、输入资料、量化指标、交付记录和检查方式。

# 硬性约束
1. 不编造产品利益、客户资料和成功业绩。
2. 不承诺保本、保收益，不把非保证利益表述为确定收益。
3. 不未经授权使用客户敏感信息。
4. 产品推荐必须以适用条款、客户需求和适当性要求为依据。
5. 无法核实的案例，只提供案例模板，不编造业绩数字。
6. 目标分解必须写明假设与测算口径；假设可调整，但必须标注。
7. 所有指标必须可测量、可归集到责任人。

# 输出
先生成 Word 方案初稿，再自检：哪三章最空？哪三处最可能被支行长驳回？为什么？
第二轮提示词：业务负责人提修改意见
PROMPT 07+ · 第二轮细化
这个方案还不够具体。请做以下修改，输出细化版：

1. 把所有营销举措细化到“每日经营动作”：每个动作写清时间、地点、执行人、输入资料、交付记录、量化指标。
2. 补齐每日管控：晨会说什么、上午做什么、下午做什么、夕会复盘什么、数据何时回填、异常由谁处置。
3. 每个网点、每个岗位都要有明确的任务书，不允许出现“相关人员”“各网点自行安排”。
4. 补充真实成功案例的经验拆解：如果材料里没有可核实的案例，只写案例模板与需要采集的字段，不得编造业绩。
5. 所有目标数字必须能推到“每天每人要完成多少”，并说明测算口径与可调整假设。
6. 增加资源配置：人力、费用、物料、系统支持，各写清来源与审批环节。
7. 增加风险预案：任务滞后 20% 怎么办、活动无法举办怎么办、人员临时缺岗怎么办。

我要的不是一份写得漂亮的方案，而是一份明天就能让所有网点开始执行的作战计划。
第三轮提示词：四个视角交叉验收
PROMPT 07++ · 第三轮交叉验收
现在请分别以四个角色审阅这份方案，每个角色单独一段，只写问题，不写肯定：

一、支行行长视角：
- 目标是否可达成？依据是什么？
- 资源是否够？缺口在哪里、向谁要？
- 哪些动作投入产出不成立？
- 出问题时，我第一个被问责的环节是哪个？

二、网点负责人视角：
- 我明天早上第一件事做什么？
- 哪些动作在我的权限之外、需要谁批？
- 我的人手够不够？不够时先砍哪一项？
- 有没有互相冲突的要求（例如既要求全员外拓又要求厅堂满员）？

三、客户经理视角：
- 名单从哪里拿？质量够不够？
- 话术能不能用？遇到客户说“我再想想”怎么办？
- 考核怎么算？做了动作没成交算不算数？
- 每天要填几张表？能不能只填一张？

四、合规审查视角：
- 哪些表述有承诺收益的嫌疑？
- 适当性管理在哪一步？风险测评过期怎么处理？
- 客户信息如何使用、如何留痕？
- 双录、宣传材料、案例传播是否合规？

然后输出修正清单：逐条写明“问题 / 所在章节 / 修正动作 / 责任人 / 完成时点”，并按严重程度排序。最后输出正式交付版和一份修订说明。
