MODULE 01 1 小时

WorkBuddy 入门
与能力地图

核心问题

WorkBuddy 不只是聊天，它如何从“问答工具”升级为“业务执行平台”？

记忆点专家定角色，Skill 沉淀能力，MCP 连工具，Plan 管复杂任务。

核心内容

  • WorkBuddy 基础界面与工作方式：对话、文件、任务与结果交付
  • 专家（Expert）：固化角色、知识、规则和输出要求
  • Skill：封装重复任务的方法、步骤和质量标准
  • MCP：在授权边界内连接外部工具、系统和数据能力
  • Plan 模式：复杂任务先规划，再分步执行、检查与调整
  • 从一次性对话到 Expert + Skill + MCP + Plan 组合工作流
  • 演示链路：上传业务文件 → 规划任务 → 调用能力 → 生成可交付结果

MODULE 02 0.5 小时

自然语言驱动 Python：
数据清洗、去重
与代码纠错

核心问题

不会 Python，怎样让 AI 写出“能跑、能改、能验”的代码？

记忆点说清输入、规则、输出、校验、异常。

核心内容

  • 不讲 Python 语法，直接学习“自然语言编程”
  • 五要素任务表达：输入文件、处理规则、输出格式、校验方式、异常处理
  • 让 WorkBuddy 生成 Python 并逐段解释代码
  • 处理空值、日期、金额、文本格式，以及单字段或组合字段去重
  • 通过报错文本或截图让 WorkBuddy 自动定位、修改并再次运行
  • 核对处理前后行数、重复数、金额等关键指标

MODULE 03 0.75 小时

批量自动化：
合并报表与拆分名单

核心问题

如何把“打开文件 → 复制粘贴 → 筛选另存”变成一次自动执行？

记忆点批量读、字段齐、规则拆、总量验。

核心内容

  • 批量读取多个 Excel 或 CSV 文件并自动合并
  • 字段名、字段顺序、缺列不一致时自动对齐
  • 按机构、团队、客群、活动、状态等规则批量拆分名单
  • 自动创建输出目录，完成文件命名和结果汇总
  • 进行合并、拆分后的总量校验，识别漏数与重复
  • 根据新增业务规则局部修改代码，不从头重写

MODULE 04 0.75 小时

自动对账：
差异识别与异常清单

核心问题

两张表“看起来差不多”，怎样快速找出真正的差异？

记忆点先定主键，再分差异，最后对总账。

核心内容

  • 明确对账主键：客户号、订单号、交易号等
  • 自动分类：完全一致、仅 A 有、仅 B 有、金额不一致、状态不一致
  • 处理前导零、文本或数字类型、日期格式等常见匹配失败问题
  • 自动生成差异清单与差异汇总
  • 建立“数量 + 金额 + 异常笔数”三层校验
  • 追加新规则时，用自然语言要求 WorkBuddy 局部修改程序

MODULE 05 / 综合练习 1 小时

MCC 交易筛选
与 Skill 沉淀

核心问题

如何把一次性筛选脚本，变成以后反复可用的小工具？

记忆点规则参数化，结果可验证，能力可复用。

核心内容

  • 基于 MCC 规则表筛选交易：白名单、黑名单、指定类别、组合条件
  • 叠加金额、日期、渠道、客户等多条件筛选
  • 自动汇总交易笔数、交易金额、客户数等指标
  • 输出筛选结果、未匹配 MCC、异常数据清单
  • 形成“上传文件 → 输入规则 → 自动运行 → 输出结果”的工具流程
  • 将成熟流程沉淀为 WorkBuddy Skill 或标准任务模板
