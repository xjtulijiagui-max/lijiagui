01 / 先建立共同语言

这些名字，处在不同层

Skill：制作方法

教 AI 按什么步骤做事。shotcraft、归藏、Remotion 最佳实践都属于这一层。

框架：制作底座

真正组织画面并生成视频。Remotion 使用 React；HyperFrames 使用 HTML。

平台：剪辑工作台

ChatCut 管理素材、多轨时间线、预览和导出，通过服务工具操作。

声音：配音与转写

Voicebox 是本地声音应用；ChatCut voice 是云端配音工作流技能。

讲师口径：Skill 像工作方法，框架像制作设备，剪辑平台像操作台，声音工具像录音室。方法能调用设备，它们可以配合。
内容与证据课程资料 / 产品功能 / 原始视频
策划与导演课程归藏 / 产品归藏 / shotcraft
制作或剪辑Remotion / HyperFrames / ChatCut
声音与交付Voicebox 或其他配音 → 验收 MP4

示意流程；ChatCut 自身也可完成多种制作步骤。不要为了“用齐工具”重复做工程。

03 / 安装前的三项检查

“装了技能”，还要检查能否执行

01 · 技能可见

目录完整、SKILL.md 可读取，引用脚本和素材存在。必要时新建会话重新加载。

02 · 运行环境

按技能检查 Node / Python、FFmpeg、浏览器和项目依赖。配音模型首次可能下载。

03 · 服务连接

ChatCut 需注册与登录；Voicebox 需应用运行与连接。配置存在不代表工具可调用。

04 · 小样片验收

先生成 5 秒样片，检查文件、时长、画面和声音；把依赖缺项如实列出。

通用安装诊断提示词
请先检查本机视频制作环境，不要重装已有工具。列出相关技能名称、完整目录、运行依赖与可用连接，将状态分为：技能已发现、依赖已验证、连接已验证、样片已验证。对每条路线给出缺项和修复建议。只为我选定的【路线名称】安装必要缺项；保留已有配置与定制，不把“目录存在”报告成“全流程可用”。

本课件提供安装提示词，未在合伙人电脑上执行安装。安装命令用于选定路线后参考；无需把全部工具一次装齐。

video-shotcraft

HTML 制作底座

HyperFrames

把带时间信息和动画的 HTML/CSS 渲染成视频。普通培训网页与视频合成 HTML 是不同产物。

什么时候选

动态图解、数据展示、字卡、网页风格短片；希望沿用 HTML/CSS。

准备什么

脚本、图片、音频、品牌规范、时间轴设计。

拿到什么

视频合成 HTML、素材、MP4、预览工程。

与其他工具的区别

与 Remotion 是两种制作底座。你本机还有 CLI、Media、Registry 技能；当前官方目录已有拆分，安装时以实际官方版本为准。

安装提示词 · 交给 AI 执行
请按 https://github.com/heygen-com/hyperframes 当前官方说明，为 Codex 安装 HyperFrames 核心技能与必要运行环境。先检查已有安装和版本，保留定制。默认只安装核心集合，不盲目安装全部技能。检查 Node.js 22+、FFmpeg 和渲染浏览器，创建独立的 5 秒测试工程并渲染 MP4；报告技能位置、实际版本、缺项和测试结果。根据当前 CLI 帮助选择命令。
参考命令 · 先核对环境与当前文档
npx hyperframes skills update
npx hyperframes init my-video
使用提示词 · 替换【】后发送
用 HyperFrames 制作一支 30 秒、1080×1920 的中文动画解释视频，主题为【企业知识如何变成智能体能力】。受众是业务负责人。结构：问题—三步方法—一个例子—行动建议。采用深蓝、米白和青绿色，使用关系图和大字。先确定静态关键画面，再添加可跳转时间的动画。口播只用我提供的【narration.wav】；按音频对齐字幕。检查布局后预览并导出 MP4，同时交付 HTML、素材与检查记录。

03
React 制作底座

Remotion / remotion-best-practices

Remotion 用 React 编排和渲染视频；remotion-best-practices 是教 AI 正确使用它的技能。

什么时候选

数据驱动、多版本批量片、已有 React 工程、复杂可复用视频组件。

准备什么

React 视频组件、图片音频、字幕、可替换数据。

拿到什么

React/TSX 工程、可预览时间轴、渲染视频。

与其他工具的区别

安装最佳实践技能不等于已安装渲染引擎。shotcraft 可调用 Remotion，不能把两者当成两个互斥产品。

安装提示词 · 交给 AI 执行
请按 https://www.remotion.dev/docs/ai/skills 安装 Remotion 官方技能，目标为 Codex。先检查同名技能，保留定制。在独立目录按当前官方入门文档创建最小 Remotion 项目，检查 Node、包管理器、渲染浏览器及所需依赖。渲染 5 秒中文标题样片，报告 MP4 路径、版本和验证结果。技能安装与项目依赖安装分开说明。
参考命令 · 先核对环境与当前文档
npx skills add remotion-dev/skills
使用提示词 · 替换【】后发送
用 Remotion 和 remotion-best-practices，在独立目录制作 20 秒中文横版动画，解释【客户问题→知识库→智能体→业务结果】。用四个可复用 React 组件按帧控制动画。文案和配色从 JSON 读取，方便生成多个版本；保留中文字体和阅读时间。交付源代码、示例 JSON、MP4，并检查首尾帧与字幕溢出。

准备什么

本地声音工作室

Voicebox / voicebox

Voicebox 应用管理声音档案、语音生成与转写；voicebox 技能指导 AI 通过连接使用这些能力。

什么时候选

本地配音、朗读、语音笔记和转写；需要复用自己的声音档案。

准备什么

文本、原始音频、现有声音档案；应用与模型需可用。

拿到什么

06 / 90 分钟课堂安排

用一个案例，跑通一次交付

00–15 分钟看懂地图

说明四层分工。让每位合伙人拿一个真实需求，判断素材、目标与主路线。

15–30 分钟安装与验证

每组只装所选路线。检查技能、环境和连接，渲染或导出 5 秒样片。

30–60 分钟制作 30 秒样片

统一题目：“企业知识如何变成智能体能力”。准备一页材料、一段录屏、三张授权图片。

60–75 分钟定向修改

根据同伴反馈，修改具体时间窗的字卡、照片或声音；保留其他已验收部分。

75–85 分钟交叉验收

用下方清单检查真实文件；比较各路线的内容清楚程度和后续可改性。

85–90 分钟沉淀工作包

保存提示词、工程、素材来源和版本。讲清下次同类任务怎么复用。

定向修改提示词 · 让反馈可执行
请在现有工程【路径或项目名】中修改：00:08–00:12 的主字卡改为【新文案】，字号增大约 15%，至少停留 2 秒；00:20 的图片换成【指定素材】，该段背景音乐降低以突出人声。保留已验收的其他内容和画幅，使用新输出文件名。修改后重新预览这些时间窗，再导出并核验最终文件。

合伙人交付验收清单

  • 拿到可播放 MP4，画幅和时长符合要求，首尾没有意外黑屏。
  • 观点和产品功能有依据，示意画面不冒充真实客户现场。
  • 字幕准确、手机可读、字卡不遮脸、不与底部字幕重复堆叠。
  • 人声可听清，背景音乐不过响；检查关键术语和转场声音。
  • 交付可修改工程、实际使用素材及来源、口播与字幕、检查记录。
  • 记录使用的版本、已验证项目和未核验项；定制版路径已适配本机。
课堂常见问题与处理

技能看不到：先核对目标工具和目录，必要时开启新会话。
能写代码但不能出片：查运行依赖和渲染浏览器，先验证小样片。
ChatCut 401：检查登录授权，重装技能不能解决身份问题。
Voicebox 不可用：检查应用、本地地址、模型下载及声音档案。
课程技能找不到照片：更换 preferences.json 中的素材路径并核对授权。
中文字幕异常：检查字体、编码和版式，逐帧抽查关键字卡。
