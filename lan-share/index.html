局域网共享文件夹操作指南

开始前先分清两台电脑

共享端：存放文件的电脑

例如同事A的电脑。需要选择文件夹、授权账户，并保持开机联网。

访问端：打开共享文件的电脑

例如你的电脑。负责输入账户密码连接，并把共享文件夹映射成网络盘。

两台电脑连接办公室同一台路由器的普通 Wi-Fi。双方都设为“专用网络”；谁要向别人提供文件，谁就配置自己的共享文件夹。

设为专用网络→开启共享→授权文件夹→输入密码连接→固定到此电脑
先用两台电脑做通，再给其他成员按同样流程配置。每人可以共享自己的文件夹，也可以约定一台电脑集中存放团队资料。
01

设置为专用网络

两台电脑都操作
  1. 按 Win + I 打开 Windows 设置。
  2. 进入 网络和 Internet → Wi-Fi → 当前连接网络的属性。
  3. 在“网络配置文件类型”中，选择 专用网络。
操作示意 · 网络属性中的选项

网络配置文件类型

◉ 专用网络

供家庭或办公室等可信网络使用，允许电脑被网络中的其他设备发现。

如果当前页面标题是“高级网络设置”，这里不会直接显示“专用网络”。点击窗口左上角的返回箭头，回到“网络和 Internet”，再进入 Wi-Fi 属性。不要点击适配器旁的“禁用”。

插网线的电脑：设置 → 网络和 Internet → 以太网 → 网络配置文件类型 → 专用网络。

02

开启网络发现和文件共享

共享端；互相共享时双方都操作

设置 → 网络和 Internet → 高级网络设置 → 高级共享设置

  1. 展开 专用网络。
  2. 打开 网络发现；如有“自动设置网络连接的设备”，一并勾选。
  3. 打开 文件和打印机共享。
  4. 在“所有网络”中，保持 密码保护的共享 开启。
访问端也开启“网络发现”，这样更容易在文件资源管理器的“网络”列表中找到共享电脑。用账户密码连接，首次勾选记住凭据后通常无需重复输入。
03

选择文件夹，设置共享账户

在共享端操作

例如，在同事A电脑上新建一个“团队共享”文件夹，把需要共享的资料放进去。

  1. 右键这个文件夹。Windows 11 如只显示简化菜单，先点 显示更多选项。
  2. 将鼠标移到 授予访问权限(G)，再选择 特定用户…。
  3. 选择共享端电脑上要授权的账户，点“添加”。
  4. 设置“读取”或“读取/写入”权限，点击“共享”。
  5. 记下完成页面显示的网络路径；也可通过 文件夹属性 → 共享 查看。
权限访问者可以做什么
读取打开、查看、复制到自己的电脑。
读取/写入在共享文件夹中新增、修改和删除文件。

共享账户怎么选

选用共享端电脑上已存在、带密码的账户。如果需要专门给团队使用，可先到“设置 → 账户 → 其他用户 → 添加账户”，选择“我没有此人的登录信息”→“添加没有 Microsoft 账户的用户”，创建一个带密码的普通本地账户，例如 share_user，再回来添加权限。

右键文件夹的共享窗口负责选择账户并授权；新建账户在 Windows 设置中完成。首次配置优先使用本地账户，用户名和密码更容易核对。

网络路径长什么样

\\OFFICE-PC\团队共享

这是示例：请替换成你实际看到的设备名和共享名。共享路径以两个反斜杠开头；共享端的 D:\团队共享 是本机路径，不能直接拿来连接另一台电脑。

04

在“网络”里找到电脑，输入密码

在访问端操作
  1. 按 Win + E 打开文件资源管理器。
  2. 在左侧点击 网络；如果靠下看不到，向下滚动左侧导航。
  3. 在“计算机”区域找到对方的电脑，双击打开。
  4. 弹出“输入网络凭据”时，填写共享端已获授权账户的用户名和密码。
  5. 勾选 记住我的凭据，确认后打开共享文件夹。

如果登录框默认显示你的账户，点击 更多选择 → 使用其他账户，再填写正确账户。用户名中的设备名必须是对方的实际 Windows 设备名。

“网络”里没有显示对方电脑

可以直接在文件资源管理器顶部地址栏输入第 03 步得到的共享路径，再按回车。共享服务正常时，即使列表未显示电脑，也可能通过路径连接成功。

例如输入 \\OFFICE-PC\团队共享。若设备名解析失败，也可使用对方当前 IPv4 地址，如 \\192.168.1.23\团队共享；这里的地址只是示例。

05

把共享文件夹固定到“此电脑”

在访问端操作

映射后，共享文件夹会显示成一个网络盘。以后打开“此电脑”，双击这个盘就能进入，不必每次从“网络”里寻找。

  1. 按 Win + E 打开文件资源管理器。
  2. 右键左侧的 此电脑 → 映射网络驱动器…。有些界面右键“网络”也有该入口，可以沿用你实际看到的菜单。
  3. 选择一个未使用的盘符，例如 Z:。
  4. “文件夹”填写第 03 步的完整共享路径。
  5. 勾选 登录时重新连接。需要使用对方共享账户时，勾选“使用其他凭据连接”。
  6. 点击“完成”；如弹出登录框，输入已授权的共享账户密码并记住凭据。

如果右键没有“映射网络驱动器”，先打开“此电脑”，再点击顶部的 … → 映射网络驱动器。不要对着普通文件夹右键寻找这个入口。

连接后给网络盘改名

在“此电脑”的“网络位置”中找到新出现的盘，右键 → 重命名，改为“同事A共享”。给 同事B 添加共享盘时，选另一个空闲盘符，例如 Y:。

操作示意 · “此电脑”中的网络位置
同事A共享（Z:）连接到同事A电脑上的共享文件夹
网络盘示例实际位置
同事A共享（Z:）同事A电脑上的共享文件夹。
同事B共享（Y:）同事B电脑上的共享文件夹。

Z: 和 Y: 只是你电脑上的访问入口，不会移动对方的文件，也不会自动同步一份备份到你的电脑。

06

检查是否配置成功

按下面几项检查。读取/写入权限请用一个临时测试文件验证。

已检查 0 / 6 项
共享端需要开机、联网且未进入睡眠。重新连接选项会保留连接设置；对方电脑关机时，网络盘可能显示红叉，恢复上线后再打开连接。

遇到问题怎么处理

同一个 Wi-Fi，但找不到对方电脑

确认两台电脑连接普通办公室网络，而非访客 Wi-Fi；检查是否开启网络发现。若列表仍未显示，直接输入共享路径。若路径也不通，检查路由器是否开启“AP 隔离 / 客户端隔离”，以及共享端防火墙是否允许专用网络下的文件和打印机共享。

提示用户名或密码不正确

输入的是共享端账户，不是访问端账户；本地账户可使用“对方设备名\账户名”。核对账户密码，不能使用 PIN。若 Windows 保存了错误凭据，在控制面板 → 凭据管理器 → Windows 凭据中，只删除或修改这台共享电脑对应的旧凭据，再重新连接。

能看到文件夹，但提示没有访问权限

在共享端检查文件夹“共享”权限以及“安全”选项卡中的文件系统权限，两处都要允许该账户访问。需要写入时，检查两处是否都授予了相应权限。

网络盘显示红叉，或者时通时不通

先确认共享端开机、联网且没有睡眠，再打开网络盘。如果使用 IP 地址连接，路由器重新分配地址后路径可能失效；可在路由器为共享端保留固定地址，或改用能够正常解析的设备名连接。

怎样取消映射

在自己的“此电脑”里右键对应网络盘，选择“断开连接”。这只移除本机入口，不会删除对方的文件。停止文件夹共享，需要在共享端修改共享设置。

两个人同时改同一个文件怎么办

文件共享不自动提供多人同时编辑能力。按软件的文件锁定提示操作，约定编辑人；需要共同编辑的文档，使用支持协作编辑的工具。
