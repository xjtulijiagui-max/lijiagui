MODULE 01 · 认知破壁与协同逻辑

从“工具”到“同事”的 Agent 革命

看清 Agent 的组成、行动链路，以及“人—Agent—Agent”的新协作方式。

四大核心要素

LLM 大脑、规划能力、记忆系统、工具调用。Agent 不止生成文字，还能在授权范围内执行任务。

ReAct 闭环

观察 → 推理 → 行动 → 反馈 → 再判断，强调基于真实系统反馈推进工作。

多 Agent 协作

管理者 Agent 拆任务、执行 Agent 处理、质检 Agent 复核；高风险节点仍需人工裁决。

课堂模拟：一张校园食材配送异常单如何流转？

数据/工单进入→执行 Agent 归类与初筛→质检 Agent 检查证据→业务负责人复核裁决→记录结果与改进规则

注意：食品安全、供应商处罚、财务付款、涉及个人隐私等高风险事项必须按授权流程人工复核，不得由 AI 自主作最终决定。

MODULE 03 · 组织架构与管理模式

管理“硅基员工”：碳基 + 硅基协同

把数字员工纳入职责、监督、评价与审计，不是简单多开几个聊天窗口。

人类管理者
  • 定目标、批准授权
  • 判异常、作最终裁决
  • 承担业务结果与安全责任
数字员工 Agent
  • 取数、查验、归类
  • 执行已授权动作、出初稿
  • 记录依据、上报异常
AI 运营 / 治理支持
  • 身份、权限、审计日志
  • 质量监测、成本管控
  • 熔断、版本回退与淘汰

一种可讨论的治理模式是“AI运营中台提供技术与治理，业务部门按需使用并承担业务结果责任”；具体组织架构与数字员工使用机制须由内部审定。

任务完成率结果准确率单任务成本响应时效

可按“初级执行型 → 高级决策辅助型”讨论 Agent 虚拟职级；是否实施数字员工工号、编制或晋降级制度，应由公司内部制度审定，课程不预设已落地。

MODULE 04 · 落地路线图与变革管理

把 Agent “装进”组织的五步法

不追求一次建成，而是先选可验证试点，再扩展可治理的规模化应用。

01流程挖掘

梳理流程、节点、岗位、系统与当前痛点。

02就绪度评估

核对数据基础、API 开放性、团队接受度。

03治理与安全

最小权限、日志审计、人工复核、业务熔断。

04明星试点

优先低风险、业务感知强、能前后对比的场景。

05规模复制

形成标准 SOP、运营机制与多 Agent 协作。

人的转型同样重要：把部分重复操作岗位升级为规则维护者、AI 训练师、审核员和异常裁决官；以业务价值和风险成本评价试点，不盲目追求 Agent 数量；可讨论将“AI 引入成效”纳入业务负责人 OKR 的激励方式。
