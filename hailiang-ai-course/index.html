模块一 · 选准场景

选准场景

从“校园报修工单跟进”开始，用三个轻量判断找到 AI 真正帮得上的环节：

  • 这件事是否重复、费时或容易遗漏？
  • 材料是否拿得到、说得清？
  • 结果是否能由人检查并承担责任？
贯穿案例：校园报修工单跟进不是做一张报表，而是让受理、派工、处理、验收、超时风险和下一步更清楚。

模块二 · 拆清任务

拆清任务

把真实工作拆成三段：输入材料、处理动作、输出结果。先说人话，再用 IPO 结构整理，跟着示例完成即可。

  • 输入：AI 需要看什么、缺什么？
  • 处理：哪些判断必须由人做，哪些整理可交给 AI？
  • 输出：交付给谁、长什么样、怎样算合格？

模块三 · 专家协同

培养专家与专家团协作

沿用模块二 IPO，先培养一名 AI 专家，再根据任务需要设计专家团协作，最后由人审核成果。

  • 3.1 专家配置：人设、能力模型、工作流程和边界。
  • 3.2 专家团：专业分工、任务接力与人工检查点。
  • 3.3 协同与验收：检查工单来源、状态冲突和异常风险。

模块四 · 固化复用

固化复用

老师展示如何保存有效规则、更新材料、再次复测。学员只需理解“为什么沉淀、沉淀什么、如何验证”，不要求现场制作 Skill。

  • 先保留可复用的方法记录和检查清单。
  • 材料或规则变化后，及时更新并重新验证。
  • 稳定、高频、反复验证后，再考虑 Skill 等载体。

模块五 · Spec 驱动工作台（进阶）

从 IPO 到可预览的后勤工作台

沿用“校园报修工单跟进”贯穿案例：将模块二 IPO 与 Spec Workspace 标准一起处理，先形成可评审的规格包，再按照规格搭建工作台原型。

  • 第一步：IPO + Spec 标准 → 生成 Workspace 规格与验收要求。
  • 第二步：按规格搭建“工单导入、异常核对、结果导出”原型。
  • 只使用模拟数据；工单验收、结案与安全相关判断由人工负责。
