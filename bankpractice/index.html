# 输出要求
先输出工作方案（Markdown），再输出一页纸摘要（表格或要点）。

不虚构客户、金额与项目；文末标注"本方案为教学模拟"。

制度查询 · 串联与证据链实战

素材包 B：4 份模拟制度 + 1 份补充通知（含冲突点）

用户故事

你是江城银行合规管理岗 / 内审岗助手。 监管检查临近，需要就一笔具体业务给出制度依据："单户 9000 万元、属于绿色信贷目录的授信，分行能否自行审批并走快速通道放款？" 你收到：01_授信业务管理办法、02_流动资金贷款管理暂行办法、03_反洗钱客户身份识别与尽职调查制度、04_信贷审批权限与流程规定、05_补充通知_优化授信审批流程 你要交付：制度证据链 + 权限/流程结论 + 冲突与待确认项 使用工具：任意 AI 对话或知识库工具

练习目标

把多份制度按"效力层级 + 新旧优先"串联成证据链，并准确识别制度间的冲突（如审批权限差异）。

练习路径

1下载资料获取 5 份制度文件
2打开工具上传全部制度
3复制提示词提问并生成证据链
4找冲突核对权限差异与例外条款

可复制提示词

你是一名江城银行合规管理岗 / 内审岗助手。

# 任务背景
监管检查临近，需要就"一笔单户 9000 万元、属绿色信贷目录的授信业务，分行能否自行审批并快速放款"给出制度依据与证据链。

# 输入资料
我将上传 5 份制度：01_授信业务管理办法、02_流动资金贷款管理暂行办法、03_反洗钱客户身份识别与尽职调查制度、04_信贷审批权限与流程规定、05_补充通知_优化授信审批流程。

# 任务目标
构建该笔业务的"制度证据链"，并明确指出权限与流程结论。

# 处理要求
1. 按"效力层级 + 新旧优先"原则串联制度：新文优于旧文、上位法优先。
2. 针对该笔业务逐条检索并引用相关条款，标注发文号与条目。
3. 必须识别制度间冲突（如审批权限上限在办法/规定/通知中的差异），并说明以何者为准及理由。
4. 给出结论：分行是否有权审批、是否适用绿色快速通道、还需满足哪些前提（如 KYC、贷审会/双签）。
5. 用"证据链"形式输出：结论 ← 关键条款 ← 制度依据。

# 输出要求
输出：①一句话结论；②制度证据链（含引用）；③冲突与待确认项；④合规前提清单。

# 约束
仅依据上传制度，不引入外部臆测；文末标注"本练习为教学模拟"。

数据分析 · 图表与核验实战

素材包 D：脱敏 Excel（趋势/排名/异常）+ 字段说明 + 问题清单

用户故事

你是江城银行计划财务部数据分析岗助手。 收到一份脱敏的各支行经营数据（Excel），含规模、效益、质量与同比趋势，但存在业务异常与数据质量疑点。 需要完成数据分析、可视化与核验，并产出管理洞察，供行领导三季度督导决策。 你收到：01_经营数据.xlsx、02_字段说明.md、03_管理问题清单.txt 你要交付：数据质量核验 + 关键图表 + 异常诊断 + 重点督导名单 使用工具：支持表格/图表的 AI 或 BI 工具

练习目标

先核验数据质量、再分析趋势与异常，用图表说话，输出可行动的管理建议。

练习路径

1下载资料获取数据三件套
2打开工具上传 Excel
3复制提示词核验+分析+出图
4找异常定位需督导支行

工具入口

模拟资料下载

02_字段说明.md

03_管理问题清单.txt
待核验疑点（含数据质量项）

可复制提示词

你是一名江城银行计划财务部数据分析岗助手。

# 任务背景
收到一份脱敏的各支行经营数据（Excel），含规模、效益、质量及同比趋势，但存在业务异常与数据质量疑点。需要完成数据分析、可视化与核验，并产出管理洞察。

# 输入资料
我将上传：01_经营数据.xlsx、02_字段说明.md、03_管理问题清单.txt

# 任务目标
完成数据分析报告：含关键图表、异常诊断、数据质量核验与管理建议。

# 处理要求
1. 先核验数据质量：对"管理问题清单"中的疑点逐项核对（如空港支行存款同比 -220% 疑似录入错误），给出修正后的合理值并说明依据。
2. 用图表呈现：各支行存款排名、不良率分布、存款同比趋势（柱状/条形图）。
3. 量化诊断：不良回升的主要贡献支行及其占比；指出"增量不增效"的支行。
4. 依据字段说明口径计算，不臆造指标。
5. 输出需重点督导的支行名单及原因。

# 输出要求
输出：①数据质量核验结果；②3 张图表（可用 Mermaid/ASCII 或描述）；③异常诊断；④重点督导名单与管理建议。

# 约束
所有结论基于上传数据；文末标注"本分析为教学模拟"。
