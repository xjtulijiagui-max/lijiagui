维护说明：以后新增网页如何自动进入导航

新网页目录中同时放一个 nav-meta.json。推送到 GitHub 后，仓库里的 GitHub Action 会扫描这些元数据，并自动重建 navigation/nav-data.js。如果不希望某个页面进入导航，就不要放这个文件。

{
  "id": "project-key",
  "title": "客户 / 项目名称",
  "shortTitle": "菜单短名称",
  "category": "制造能源与工业",
  "description": "一句话说明这个练习解决什么问题",
  "path": "new-project/",
  "tags": ["知识库", "工作流", "智能体"],
  "type": "客户项目",
  "client": "客户名称",
  "featured": true,
  "order": 350
}

推荐以后给网页生成工具统一追加一句：“同时生成 nav-meta.json，并加入 AI 实战训练导航。” 这样网页和导航会像火车与时刻表一样同步更新。
