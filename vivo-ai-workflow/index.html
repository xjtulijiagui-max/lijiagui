案例 · 复制使用

项目跟进 IPO（模拟）

用于演练，不代表真实项目。

【任务】整理一份内部项目进展简报。
【已确认 IPO】
I：项目台账、会议纪要、风险清单。
P：核对资料 → 汇总进展与风险 → 人工确认 → 起草简报 → 验收。
O：一页简报，包含进展、风险、下一步；结论要有来源。
【背景材料】
台账：项目A拟11月6日上线；项目B风险“低”。
会议纪要：项目A测试尚未完成，上线时间待定。
风险清单：项目B风险“高”，原因待核对。
【约束】仅教学模拟；冲突数据标待确认，不自动发布。
01
3.1 补齐 C / H / A · 8分钟

补角色、补背景、补目标；T 就是已确认的 IPO。

3.1 · 复制使用

先让 AI 理解任务

复制后只改三个位置：C 谁负责、H 有什么背景、A 想得到什么。

沿用上文已确认的总 IPO，不要重写。

请补齐 CHAT：
C：我是【岗位】，负责【业务判断/审批】；你是 AI 助手，负责【交给AI的工作】。
H：任务背景【】；现有资料及时间【】；缺失资料或限制【】。
A：本次目标【】；交付对象和用途【】。
T：就是上文已确认的 IPO。

本轮只输出《任务执行准备单》：
已知条件｜缺失资料｜人工确认事项｜可开始的第一步。

没有依据的标“待确认”，不要生成最终成果。

学员检查：AI 有没有说清楚已知信息、缺失信息和能先做哪一步？产出：任务执行准备单。

02
3.2 输出人机接力表 · 14分钟

让 AI 把原 IPO 的处理步骤整理成表，便于人检查。

3.2 · 复制使用

一张表看清谁做什么

重点看“AI做什么、人工检查什么、能不能继续”。

沿用已确认的 IPO 和 3.1《任务执行准备单》，不要重写 IPO。

请按原 IPO 的 P，输出一张《人机接力表》：
步骤｜需要的输入｜AI做什么｜人检查/确认什么｜阶段输出｜能否进入下一步。

缺资料、口径冲突或需要审批的地方标“待确认”。
本轮只输出表格，不执行后续任务。

学员检查：每一步有没有明确分工？需要人确认的地方有没有标出来？产出：人机接力表。

03
3.3 输出验收检查表 · 13分钟

沿用原 IPO 的 O，检查已有成果，不自己发明验收标准。

3.3 · 复制使用

一张表检查做得对不对

重点看“原标准、证据、问题、由谁确认”。

沿用原 IPO 的 O 和 3.2《人机接力表》，核对目前实际已有的成果。

请输出一张《验收检查表》：
检查项｜原验收标准｜证据/来源｜检查结果｜问题与修改建议｜谁来确认。

结果只能是：符合 / 不符合 / 待确认 / 未开始。
没做的不能写成完成；AI只做初检，最终由人确认。

学员检查：没有证据的结论是否标“待确认”？未完成的有没有误写成完成？产出：验收检查表。

完成标志：拿到三张单表：任务执行准备单 → 人机接力表 → 验收检查表。最后由人决定是否通过。
