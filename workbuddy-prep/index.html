装好 WorkBuddy，下载正确的版本

展开

这一步最容易出问题。上次课最大的坑就是：电脑里装的不是最新版，界面和大家不一样，一节课都在找按钮。

先检查你的系统和硬件

WorkBuddy 的主形态是电脑桌面端，课程实操要求 Windows 或 macOS 电脑。开工前先对一遍：

检查项最低要求怎么查
Windows 系统 Windows 10 及以上
不支持 Windows 7 / 8 / 8.1		 设置 → 系统 → 关于 → Windows 规格
macOS 系统 macOS 12.0 及以上 左上角 苹果菜单 → 关于本机
Mac 芯片类型 必须分清 Apple 芯片 / Intel 关于本机 → 「芯片」显示 Apple M 系列=Apple 芯片；显示 Intel=Intel 芯片
网络 可正常联网（调用 AI 模型服务） 浏览器能正常打开网页即可
账号 已注册并登录 WorkBuddy 账号 首次登录即完成注册
版本 升级到最新版本 客户端内检查更新；旧版本界面与课程演示不一致
⚠️ 必须提前装，不要留到课堂上 安装、登录、升级这类事，一个人卡十分钟，全班就要等十分钟。请在开课前全部完成，并确认能正常发起一次任务。

登录与注册：一次扫码就完事

  1. 打开电脑客户端，点「登录」，会自动拉起浏览器打开 workbuddy.cn。
  2. 用微信扫码登录。也支持手机号、邮箱或企业 SSO。
  3. 首次登录即完成注册，不需要单独注册账号。
  4. 如果还要用手机 App：请确保 App 登录的微信账号与电脑端是同一个，否则「连接电脑」功能用不了。
✓ 装完怎么算合格 打开客户端 → 已登录 → 能正常发起一次任务并拿到结果。这三点都通了，才算准备工作完成。
02

花十分钟，读懂 WorkBuddy 是什么

别带着「不就是个聊天机器人」的印象来上课。

它不是聊天框，是会动手的同事

WorkBuddy 是腾讯推出的全场景职场 AI 智能体桌面工作台。你说一句话，它自己拆任务、自己规划步骤、自己去操作文件，最后交给你可以直接用的文档、表格、PPT。

课程里用到的核心能力有三条：

  • 读写本地文件——能处理你授权文件夹里的真实资料，不是空谈。
  • Skill 扩展——把一套做法固化成技能包，这就是我们课程要教你的重点产出。
  • 多端协同——桌面端干活，手机 App 下指令、远程遥控。

提前走一遍 IPO 转 Skill 应用案例

这一步不复杂，但课前体验过，第二天实操会顺很多。

IPO 转 Skill 应用案例 · 三步走

1

输入文档

扔给它一份真实业务文档。表格、流程说明、你现在天天在做的那件事，都可以。

2

写提示词转 SOP

写一段提示词，让 AI 把这份文档整理成标准作业流程 SOP。

3

再写提示词转 Skill

再写一段提示词，把 SOP 变成可直接调用的 Skill。到这一步，智能体就成型了。

过程本身很简单。重点是先体验一遍「业务 → 智能体」的完整链路，知道每一步在干什么，第二天上手不慌。

04

完成课前 IPO 作业

只填三格，填多少算多少，不强制、不设门槛。

只填输入、处理、输出

从一个你熟悉的真实业务场景出发，拆出三件事：

要素要写什么举个小例子
I · 输入（Input） 这件事的起点是什么资料、什么请求、什么数据 客户递交的一沓申请材料
P · 处理（Process） 中间要经过哪些判断、核对、计算、流转步骤 核对要素是否齐全 → 查规则 → 出结论
O · 输出（Output） 最后要交出去什么结果、给谁、以什么形式 一份审核意见 / 一张明细表 / 一段可复制的话术
⚠️ 量力而行，但请尽量提交 模板里其他字段是拓展参考，不强制填。我会根据大家提交的内容，制作一份泛金融领域的参考 Demo，课上给到每个人。你课前填得越具体，这份 Demo 对你越有用。

现场须知与自检清单

下面每一条都踩过坑。出发前逐条打勾。

带什么

  • 笔记本电脑——Windows 或 macOS，必须带。最好不要鸿蒙或者苹果的平板。
  • 电源适配器——现场有插线板，但适配器得自己带。
  • 已装好并升级到最新版的 WorkBuddy——并已登录成功。
  • 一个你真实的业务场景——课上拆的就是它，别空手来。

现场我们准备：插线板、HDMI 线、白板，网络已提前调试。50 人同时联网，网络会做冗余保障。
