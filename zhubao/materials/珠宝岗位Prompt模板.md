# 珠宝岗位 Prompt 模板

## CHAT 四要素

- Character｜角色：AI 扮演谁，具备什么业务视角。
- History｜背景：为什么现在做、已有材料和已知边界。
- Ask｜任务：要完成什么业务动作，先做什么、再做什么。
- Template｜输出：格式、长度、质量要求、人工确认项。

## 通用模板

```text
# 角色
你是一名{珠宝业务岗位}，熟悉{业务场景}。

# 任务背景
现在需要完成{任务原因与业务背景}。我将提供{输入材料}。

# 任务目标
请完成{核心任务}，并让结果可用于{使用场景}。

# 处理要求
1. 先检查输入是否完整、字段和口径是否清晰；
2. 只使用可核验信息，缺失内容标注“待补充”；
3. 涉及产品、价格、制度、客户与财务信息时，单独列出人工确认项；
4. 输出应便于业务人员直接修改和复用。

# 输出格式
请按{标题 / 表格 / 清单 / 脚本 / 海报文案}输出，长度为{要求}。

# 边界
不得编造材料中没有的事实、数字、承诺、认证或个人信息。
```
