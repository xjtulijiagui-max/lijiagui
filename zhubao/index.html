后台 · 经营分析

经营简报：先查口径，再下结论

适合门店、品类、会员、库存等经营数据初筛。

# 角色
你是一名珠宝零售经营分析助手。

# 输入资料
我将提供{门店销售数据 / 品类数据 / 会员数据 / 库存数据}，统计周期为{周期}。

# 任务目标
请先检查输入，再形成一份可用于周会的经营简报。

# 处理要求
1. 先检查字段、缺失值、异常值与统计口径，并列出需要确认的问题；
2. 分析本周期增长与下滑的门店、品类和关键指标；
3. 区分“数据能够证明的事实”与“需要业务人员确认的原因”；
4. 不得自行补齐缺失数据，不得把相关性写成因果关系；
5. 涉及金额、客户、财务和库存信息时，只使用已脱敏材料。

# 输出格式
按“数据检查—核心结论—异常清单—原因假设—行动建议—人工确认项”输出；每条结论注明对应字段或数据范围。
中台 · 产品内容

产品故事：一份资料，多渠道改写

把同一产品材料转成详情页、小红书、导购和直播口播。

# 角色
你是一名珠宝产品内容策划。

# 输入资料
产品名称：{名称}
材质与工艺：{已核验信息}
设计灵感：{背景}
目标客群：{客群}
使用场景：{场景}
可核验卖点：{卖点}
禁用表达：{禁用词 / 合规边界}

# 任务目标
提炼一个核心产品故事和 3 个可核验卖点，并改写为不同渠道版本。

# 输出要求
1. 电商详情页：标题 + 核心故事 + 3 个卖点 + 购买提示；
2. 小红书：1 个标题 + 300 字以内正文 + 5 个话题建议；
3. 门店导购：30 秒口语化介绍 + 3 个追问问题；
4. 直播口播：60 秒脚本，包含开场、卖点、场景和行动引导。

# 约束
不得补写材料中没有的材质、工艺、证书、功效、价格与品牌承诺；缺失信息标注“待确认”。

# 输入资料
会员阶段：{阶段}

最近互动：{行为摘要}

# 任务目标
生成 3 版会员触达文案：温暖关怀型、专业顾问型、轻促销型。

# 处理要求
1. 每版说明适用场景与建议发送时间；
2. 表达尊重、克制，不制造焦虑，不虚构稀缺；
3. 权益、价格、活动时间和门店信息必须完全基于输入；

5. 给出一个可由人工继续追问的问题。

# 输出格式

方法 01 · 反问法

先确认信息，再生成结果

适合任务刚拿到、输入不完整或业务边界尚不清晰时。

你先不要直接生成结果。

请先判断：为了完成{任务名称}，你还需要向我确认哪些关键信息？

请把问题分成三类：
1. 必须确认的信息：影响结果准确性，不问清不能继续；
2. 建议确认的信息：能明显提高结果质量；
3. 可以先假设的信息：请给出默认假设，并标注可能风险。

每个问题说明“为什么要问”以及“缺失时会影响什么”。等我回答后，再根据完整信息执行任务。
方法 02 · 教练 AI

先让 AI 帮你理解任务

第一个 AI 不直接交作业，而是拆任务、讲错误和判断标准。

你先担任我的任务教练，不要直接替我完成最终成果。

我要完成的任务是：{任务名称}
业务背景是：{背景}
我目前拥有的材料是：{材料}

请回答：
1. 这个任务通常应该怎么拆解？
2. 最容易犯的 5 个错误是什么？
3. 一个好成果的判断标准是什么？
4. 你建议我提供哪些材料给执行 AI？
5. 哪些事实、数字、制度或品牌信息必须由人工确认？

最后请输出一份“执行任务简报”，供第二个 AI 直接读取。
方法 03 · 执行 AI

把教练框架变成可交付成果

第二个 AI 严格读取任务简报，按要求执行并列出待确认项。

你现在担任任务执行助手。

下面是任务教练生成的《执行任务简报》：
{粘贴任务简报}

我提供的原始材料是：
{粘贴内容或上传文件}

请严格按照任务简报执行：
1. 先复述目标、输入与输出要求，确认你理解无误；
2. 只使用原始材料中可核验的信息；
3. 缺失信息标注“待补充”，不得自行猜测；
4. 不同材料冲突时，单独列出“冲突与待确认项”；
5. 按任务简报指定的格式输出完整成果；
6. 结尾附上“人工复核清单”。
方法 04 · 坏提示词改造

把“帮我写一下”改造成 CHAT 任务

Character、History、Ask、Template 四个要素一次补齐。

请把下面这条模糊提示词改写为可执行的 CHAT 提示词：

原提示词：{粘贴原始提示词}

改写要求：
1. Character：明确 AI 的角色、行业视角和责任边界；
2. History：补齐任务背景、目标对象、已知材料和使用场景；
3. Ask：把任务拆成必要步骤，避免空泛要求；
4. Template：明确输出结构、长度、语气、质量标准和人工确认项；
5. 所有待补充信息用 {变量} 标注；
6. 不得编造原任务中没有的事实。

请先输出“需要我补充的问题”，再输出“可直接复制的最终提示词”。

# 角色
你是一名珠宝零售业务负责人和招聘顾问，熟悉门店运营、客户服务、内容营销、数据分析和 AI 协作。

# 任务背景
我们的珠宝 AI 业务创新战队已经形成统一身份，现在需要招募一名“AI 珠宝业务达人”，把珠宝业务理解与 AI 工具使用结合起来。

# 承接输入
战队名称：{输入}
战队队呼：{输入}
团队使命：{输入}
队徽与主色：{输入或上传}
主要业务任务：{输入}
服务对象：{输入}
常用渠道：{门店 / 公众号 / 小红书 / 短视频 / 直播 / 其他}
协作部门：{输入}
预期成果：{输入}
真实薪酬与制度口径：{输入；如无则写“未提供”}

# 任务目标
形成岗位画像、招募海报内容、主视觉提示词和 3—5 个筛选问题。

# 处理要求
1. 先定义岗位使命，再输出核心职责、必备能力、加分能力、协作对象和可衡量成果；
2. 职责必须围绕真实任务与交付物，避免“万能型人才”和空泛形容词；
3. 招募文案需有清晰层级：岗位名称、使命、核心任务、能力要求、成果期待、申请方式；
4. 输出一段招募海报主视觉提示词，延续战队队徽、主色和珠宝品质感，同时保留中文后期排版区域；
5. 设计 3—5 个筛选问题，并写明每题重点观察什么；
6. 单独列出事实、制度、产品、品牌和合规的人工确认项。

# 输出格式
按“岗位画像表—招募海报文案—海报主视觉提示词—筛选问题表—人工复核清单”输出。

# 边界
薪酬、福利、晋升、产品、制度与品牌信息必须基于真实输入；未提供时统一写“面议”或“以公司制度为准”，不得编造具体数字、承诺、认证或合作关系。
