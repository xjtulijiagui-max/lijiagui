**学习目标**

· 理解AI场景的本质——业务链条重构，掌握"一高三可"高价值场景判断标准

· 了解六类场景识别工具（T1–T6）对应的六种机会来源，能从流程/知识/业务/技术断点中系统识别AI机会

· 掌握四关漏斗筛选逻辑（两高两低×2 + 场景12问 + 九要素评审），将候选机会转化为资源配置决策

· 理解POC→MVP→Pilot→ROI递进验证机制，掌握A/B Test价值归因方法，以数据证明AI场景价值

· 了解三类资产化复制路径（工具/方法/案例）与70/30复制模型，将单点成功沉淀为可复用能力

· 理解AI推广组织机制（五维推广+铁三角+月度通晒），明确各自角色在平安AI场景创新体系中的职责

| **模块一 认识AI场景创新** 09:20–10:30 · 70分钟 | |
| **AI场景的本质** | ▶ AI场景不是"找几个AI点子"，而是业务链条重构  — 不只是AI任务（动作单元：识别票据/生成话术/总结会议）  — 不只是AI工具（能力载体：OCR/RAG/Agent/ChatBI）  — 不只是AI产品（交付形态：智能客服/AI陪练/核保助手）  — 而是围绕业务目标重构：角色/任务/流程/知识/系统/指标  ▶ 判断标准：不要问"能不能用AI"，而要问"这条链条哪些任务、知识、规则和系统连接可以重新组织" |
| **一高三可标准** | 高价值AI场景必须同时满足四个条件：  ▶ 高价值：降本/增效/提质/增收/控险  ▶ 可落地：数据/知识/系统/权限可支撑  ▶ 可验证：POC/MVP/A-B/ROI  ▶ 可复制：模板/SOP/Agent/知识库可沉淀  任何一项缺失都不宜进入组织级场景池 |
| **三大标杆案例拆解** | ▶ 智能客服——从"聊天机器人"升级为客户服务链路重构  — 高价值：降本+提质；可落地：知识库/工单/语音可接入；可验证：FCR/转人工率；可复制：员工服务/网点问答  ▶ 续收AI——从"推荐一句话术"升级为客户经营链路重构  — A/B验证多赚约2亿元；可迁移：复购/续约/客户挽留  ▶ 智能理赔——从"识别一张图片"升级为理赔流程与风控链路重构  — 自动化率82.6%，平均理赔时效7.2分钟  ▶ 辨析：场景AI化（跨岗位，导向业务目标）vs 数字员工（岗位AI化） |
| **四层价值跃迁 & 四段式总览** | ▶ AI工具层→任务重构层→流程重构层→经营机制层：判断一个场景改变了哪个层级  ▶ 四段式经营机制：识别（机会表/大场景湖）→ 筛选（Top清单/资源分级）→ 验证（MVP证据包/ROI）→ 复制（资产包/跨BU推广）  ▶ 识别、筛选、验证、复制形成闭环，从而形成组织级的AI能力 |
| **模块二 场景识别——从业务断点到AI机会** 10:30–12:00 · 90分钟 | |
| **识别来源与机制** | ▶ 识别目标：把机会看全、说清、结构化，沉淀为大场景湖  ▶ 四类来源：  — 业务痛点：客户体验差/人工成本高/风险损失大（续收AI/智能客服/健康管理）  — 流程断点：重复录入/审批等待/跨系统搬运/返工纠错（票据识别/材料审核/理赔预检）  — 知识断点：找不到/用不了/不一致/不可追溯（AskBob/知鸟AI陪练）  — 技术断点：数据孤岛/接口缺失/权限不可达/监控缺位（ChatBI/智能运营平台）  ▶ 发起机制：业务部门+科技部门联合发起为最佳，单向推销落地质量差  ▶ 颗粒度判断：点状机会→工具化普及；链条机会→专项立项 |
| **六类识别工具总览** | 六类工具对应六种机会来源，业务人员需用工具把业务问题转化为AI机会  ▶ T1 流程挖掘：固定流程/重复作业 → 案例：智能理赔/票据识别  ▶ T2 设计思维：体验断点/训练需求 → 案例：知鸟AI陪练/AskBob  ▶ T3 客户旅程：触点密集/经营链条 → 案例：续收AI/健康管理  ▶ T4 SWOT矩阵：战略机会与风险 → 案例：智能投研/反欺诈  ▶ T5 SCAMPER：流程创新/模式重构 → 案例：智能客服优化  ▶ T6 AI优先脑暴：课堂演示快速出样 → 案例：RPA+AI/ChatBI |
| **🔧 T1 流程挖掘** | 适用：固定流程/重复作业/规则清晰/系统留痕多的业务  ▶ 四步法：① 拆流程 → ② 找断点（重复录入/等待审批/跨系统搬运）→ ③ 标AI点 → ④ 画新流程  ▶ 案例：智能票据识别——15分钟/单→48秒/单，ROI 189%  ▶ 案例：存量商机转化——AI智能分群+话术推荐+最佳时机触达 |
| **🔧 T2 设计思维** | 适用：客户/员工体验强/沟通训练/服务触点复杂的业务  ▶ 五步法：共情→定义→创意→原型→测试  ▶ AI增强：多模态情感分析/聚类建模/角色扮演生成/A/B自动化  ▶ 案例：知鸟AI陪练——AI模拟客户+动态剧本+实时评分；AskBob——月活15万/解决率90%/降本1.1亿 |
| **🔧 T3 客户旅程** | 适用：续收/复购/催收/健康管理/营销转化等链条型场景  ▶ 关键动作：绘制旅程→识别MOT（关键时刻）→标注情绪痛点→设计AI介入点  ▶ 案例：续收AI——早交/晚交/犹豫/困难四类分群→千级话术推荐→A/B验证多赚2亿元 |
| **🔧 T4 SWOT矩阵** | 适用：战略机会与风险并存/投入较大/需要跨部门共识的场景  ▶ SO进攻型：平安基金智能投研（内部研究沉淀+集团数据生态）  ▶ WO转型型：ChatBI让非技术人员用自然语言查指标  ▶ ST防御型：反欺诈GNN识别团伙欺诈，降低风险损失  ▶ WT防守型：合规审查与核保留痕，降低大模型不可控风险 |
| **🔧 T5 SCAMPER** | 适用：需要替代/组合/消除/倒置原流程的创新场景  ▶ S替代（AI接管重复劳动）/ C组合（模型+知识库+API+工作流）/ A适应（通用能力迁移特定场景）  ▶ M修改（Prompt/流程快速试错）/ E消除（去掉低价值环节）/ R倒置（价值前置复杂藏后台）  ▶ 案例：SCAMPER优化知鸟AI陪练——取消低效集中培训，先AI模拟对话再看知识点 |
| **🔧 T6 AI优先脑暴** | 适用：课堂演示快速出样，帮助参训人员快速理解场景识别思路  ▶ 五问模板：① 哪些动作重复且有规则？② 哪些知识每次都在被问？③ 哪些判断可由AI先给建议？④ 哪些系统可由Agent/RPA代执行？⑤ 失败时谁兜底？  ▶ 三类机会：内部工具（提效/决策）/ 工作流自动化（减少搬运）/ 面向用户产品（增收/差异化） |
| **大场景湖 & 平安五智版图** | ▶ 大场景湖四层管理：L1价值类型/L2业务链条/L3能力模块/L4成熟度，每个场景用"场景卡"管理  ▶ 平安五智版图：智能化运营/服务/营销/管理/经营  ▶ 八个场景的发现路径示例：AskBob(T2)/ IR智能打标(T1)/ 续收AI(T3)/ 知鸟AI陪练(T2)/ 智能票据(T1)/ 舆情预警(T4) |
| **📺 讲师演示一 机会表生成 （15分钟）** | 演示形式：讲师用AI现场生成一张AI机会表，学员观察拆解思路  演示提示词（示例）：请基于【智能客服/续收触达/票据审核】业务场景，生成一张AI机会表，必须包含：场景名称/谁在做·为谁做/当前痛点/频次与规模/数据知识来源/AI可介入动作/预期价值指标/风险与边界/可能Owner/下一步验证建议  **演示流程：先定义业务链条→标出重复/等待/返工/知识断点→把AI动作写成识别/推荐/生成/校验/编排→用降本/增效/提质/增收/控险表达价值**  **观察重点：AI动作是否真正连接业务指标，而非停留在工具描述**  现场问答：学员可随时提问，讲师实时调整演示场景 |
| **模块三 场景筛选——四关漏斗找出高ROI场景** 13:00–14:30 · 90分钟 | |
| **筛选机制与四问四排除** | ▶ 筛选本质：决定有限资源投给谁、谁承担结果、用什么证据验收、沉淀成什么资产  ▶ 筛选四问（前置判断）：方向清（战略对齐）/ 价值清（指标可量化）/ 条件清（数据/知识可支撑）/ 边界清（合规/安全/兜底明确）  ▶ 四排除（慎做场景）：高情感判断/重大组织决策/复杂关系协调/强创意象征性  ▶ 错误筛选方式：只看模型先进/只听业务口号/只比Demo效果/只做领导点名 |
| **📺 讲师演示二 场景判断辨析 （10分钟）** | 演示形式：用10个典型场景快速判定，训练参训人员区分"辅助使用"与"组织级落地"  10个场景：①董事会决策是否裁员 ②高管述职演讲优化 ③跨部门冲突调解 ④品牌升级口号定夺 ⑤重要客户节日祝福 ⑥企业文化手册撰写 ⑦客服中心每天回答上千条FAQ ⑧法律灰色地带合同处理 ⑨高管战略对赌内容撰写 ⑩年会幽默编排  讲师判定逻辑：第⑦项最适合——高频/规则明确/数据可得/反馈可持续；其余多数可作辅助用  关键问答：为什么有些场景能用AI辅助，却不适合做组织级AI项目？ |
| **第一关：两高两低①** | 判断场景是否适合AI化（进入候选池的门槛）  ▶ 高能耗：海量/高频/重复，占用大量人力与时间  ▶ 高操作风险：人工容易错/漏/慢，但可由规则/模型辅助  ▶ 低失败风险：试点失败不会引发重大罚款/诉讼/不可逆损失  ▶ 低监控成本：可抽检/可留痕/可回滚，错误可被发现和纠正 |
| **第二关：两高两低②** | 业务价值 × 技术可行性四象限（"先做/后做"核心矩阵）  ▶ 先做区（高价值×高可行）：智能客服/AskBob/票据/IR打标 → 6–12周MVP  ▶ 共创区（高价值×低可行）：智能投顾/复杂风控/健康AI → 专家共创分阶段验证  ▶ 工具化区（低价值×高可行）：会议纪要/公文/表格整理 → 平台普及不重投项目  ▶ 不做/暂缓（低价值×低可行）：无Owner/无数据/无法验收 → 回到场景湖 |
| **第三关：场景12问** | 12问全过→立即立项；8–10项→共创补齐；≤7项→暂缓或转工具化  ▶ D1 商业价值（40%）：收益方是谁？金额是否可量化？不做会有什么经营损失？  ▶ D2 业务成熟度（10%）：流程是否稳定？SOP是否清晰？业务Owner是否明确？  ▶ D3 数据成熟度（10%）：数据是否可得/可信/可标？反馈样本是否可持续？  ▶ D4 技术成熟度（10%）：模型/路线是否已被验证？上线后是否可监控/可解释？  ▶ D5 持续运营（30%）：运营团队是否接得住？失败如何兜底？复制路径是否清晰？  ▶ 价值四维度量：降本（AskBob年降本1.1亿）/ 增效（DeepResearch时效提升50%）/ 提质（IR打标准确率90%+）/ 增收（续收AI多赚2亿） |
| **第四关：九要素评审 & 漏斗输出** | ▶ 九要素评审（每项1–5分）：战略对齐/业务价值/技术可行/数据就绪/合规风险/组织准备/资源投入/风险预案/可复制性  ▶ 四类伪场景可被筛掉：领导点名型/Demo炫技型/技术替代型/价值泛化型  ▶ 漏斗数字：≥200个原始机会/年 → ~80个规则过滤 → Top20九要素打分 → 10–12个年度立项  ▶ 资源分级：S类（集团重点）/ A类（专业公司6–12周）/ B类（工具化普及）/ C类（暂缓）  ▶ 协同原则：听得见炮火的人定义场景，懂得平台能力的人设计路线，掌握资源的人做组合决策 |
| **📺 讲师演示三 立项表生成 （15分钟）** | 演示形式：把一个候选机会放进统一模板，演示如何补齐Owner/指标/数据/风险/复制路径  演示提示词（示例）：基于上一步《AI场景机会表》，筛选1个最适合进入验证阶段的场景，输出一张《AI场景立项表》，必须包含：场景名称/业务目标/流程位置/AI动作/数据知识/验证指标/风险边界/复制路径，请用表格输出并补充一句立项理由  **演示流程：选"高价值×高可行"场景 → 把价值指标写成可验收口径 → 数据/知识/规则/接口分开列清 → 写明人工兜底/权限/审计/合规边界**  **观察重点：立项表是否能支撑资源投入决策，而非仅仅是方案描述** |
| **模块四 场景验证——POC到ROI的递进验证** 14:45–15:45 · 60分钟 | |
| **验证金字塔与三段论** | ▶ 验证金字塔：Demo可演示→POC可行→MVP可用→Pilot可控→ROI可证明→复制推广  ▶ 验证三段论（有先后顺序）：先技术验证（能不能做）→ 再业务验证（优于原流程）→ 后价值验证（ROI/复用率）  ▶ 管理原则：不允许"无证据上线、无复盘续投、无退出机制" |
| **POC / MVP / Pilot 要点** | ▶ POC（技术可行）：验证模型/知识库/接口/流程编排是否跑通，样本小/周期短/风险低  ▶ MVP（业务跑通）：真实用户/真实任务/小范围灰度，验证流程/体验/风险/运营机制  — 必须设计：基线指标/实验设计/效果指标/风险记录/复盘结论  — 每个MVP至少绑定：2个业务结果指标+2个过程指标+1个风险指标+1个体验指标  ▶ Pilot（价值验证）：扩大样本边界，验证稳定性/ROI/合规/组织承接  ▶ 复盘决策三动作：Scale放量（指标显著/风险可控/业务接管）/ Pivot重构（需调整）/ Kill暂停（收益不显著） |
| **A/B Test 价值归因** | ▶ 为什么强调A/B Test：把"感觉好用"转化为"数据证明"，排除季节/活动/渠道干扰  ▶ 六步法：① 定义基线 → ② 随机分组 → ③ 控制变量 → ④ 确定周期 → ⑤ 采集数据 → ⑥ 复盘决策  ▶ 案例：续收AI A/B验证——实验组AI话术推荐 vs 对照组传统方法，多赚约2亿元  ▶ 管理提醒：不要只看模型准确率，要看"业务结果是否显著优于原流程" |
